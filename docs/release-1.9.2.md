# Haiagaru 1.9.2 — DAT落ちスレを非表示の修正

DAT落ちスレを非表示の修正版です。ネイティブのDAT落ちフラグが未更新でも、公式5chの過去ログ格納済み表示を確認して補完します。設定切替・判定完了時にHOMEの未読／履歴／スレ一覧を再描画します。

## 操作と判定

- 「Haiagaru設定」の「DAT落ちスレを非表示」、または表示設定の同名項目をオンにしてください。初期値はオフです。
- 対象はHOMEの「未読・履歴・スレ」です。既存のネイティブDAT落ちフラグを優先し、フラグのない5chスレは現行一覧と公式HTMLをバックグラウンドで確認します。
- スレ一覧に載っていない、DATが404、通信が失敗した、書き込みが停止した、という情報だけでは非表示にしません。公式HTMLの投稿本文より前にある「このスレッドは過去ログ倉庫に格納されています」を確認します。本文中の引用は対象外です。
- 初回の確認が済むまでは表示を残し、確認後に一覧へ反映します。同時通信は2件、待機キューは128件まで。現行一覧・未確認結果の再確認間隔は5分、確認済みの補助情報は最大7日保持します。オフなら補助確認を新しく開始しません。
- オフにすると元の一覧を再表示します。DAT・IDX・閲覧履歴・ChMateの状態フラグは変更／削除しません。
- 補助確認の対象は5chの公式サーバーです。エッヂや外部板は、既存のネイティブ状態による判定を維持します。

## 修正内容

1. DAT落ちフラグだけの判定を、公式サイトの明示的な過去ログ表示で補完。
2. 設定変更時に板一覧だけでなくHOMEの表示コピーも更新。191／226のアダプターと242のAdapterDataへ反映。
3. 191／226で繰り返し更新した際に、オフへ戻すための元リスト参照がまとめて消える問題を修正。
4. 配布メタデータの `created_at` は `YYYY-MM-DDTHH:mm:ss` 形式を使用し、`Z`・タイムゾーンオフセットを付けません。

報告スレはDATが404、取得した現行一覧に掲載なし、公式HTMLに過去ログ格納済み表示があることを確認しました。HTMLの判定は実際の応答を含む21項目で確認しています。Android向けMPPビルドと191／226／242元APKへのパッチ適用に成功。エミュレータ（API36）でFridaを使い、191／226各51項目、242で17項目のネイティブ行・アダプター／AdapterData接続テストに合格しました。報告スレをフラグ0の行として渡す確認、設定オン／オフ、元リスト・ネイティブ状態の保持、191／226の繰り返し切替、242の既存AdapterDataへの反映を含みます。3版のDEXフックと、最近見たスレのポップアップへ接続しないことも検査済みです。実機操作と、実ユーザーの大量履歴を含む全画面の通し確認は未実施です。

対応はChMate **191 dev／226 dev／242 dev**。元APKへ再パッチし、同じパッケージ名・署名で更新してください。データ削除や初期化は不要です。
