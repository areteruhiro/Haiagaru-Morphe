# コピー履歴・分類（1.8.11）

191 dev／226 dev／242 dev対応。

「Haiagaru設定 → 履歴・保存件数 → コピー履歴・分類」、または書き込み画面の「︙ → コピー履歴・分類」から開きます。

記録は初期オフです。画面内のチェックをオンにした後に、ChMate内でコピーしたテキストを端末内の専用SQLiteデータベースへ保存します。過去のコピーや他アプリのコピー・貼り付けを収集する機能ではありません。

- 最新100件、1件10000文字まで。上限を超える長文は切り詰めず記録しません。
- 同一本文のコピーは重複させず、新しい順へ移動して分類を保持。
- 本文検索、分類別の絞り込み、全文表示、再コピー、個別削除、確認付きの全消去。
- 分類の作成・名前変更・削除。分類を削除しても本文は未分類へ戻して保持。
- 書き込み画面から再コピー後、そのまま通常の貼り付け操作で利用可能。
- 記録をオフにしても既存の履歴は残ります。不要な履歴は全消去してください。

他アプリのクリップボード監視・現在のクリップボードの読み出しは行いません。URI・Intent・複数項目・Androidの機密指定付きクリップは記録しません。ただし通常のテキストとしてコピーした個人情報等は記録されるため、利用時に注意してください。OSによる暗号化以外の独自暗号化はしません。

標準のClipboardManager.setPrimaryClip呼び出しを、元のコピー実行後に記録するブリッジへ接続します。拡張機能によるコピーも対象ですが、履歴自身からの再コピーは再記録しません。データベースの記録・検索・分類操作は専用の単一ワーカースレッドで実行します。保存に失敗しても元のコピーを妨げません。
