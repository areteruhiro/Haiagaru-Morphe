# Haiagaru 1.8.13 (Pre-release)

1.8.12からの変更です。ChMate 191 dev／226 dev／242 devに対応します。

## 更新内容

- HOMEの未読一覧が、表示上の選択に関係なく板ごとに並ぶ問題を修正しました。閲覧履歴の板別表示を未読一覧へ誤適用していた判定を訂正しています。
- 巡回画像自動保存が起動時・手動・定期巡回で動くよう改善しました。有効な保存条件がある場合、その巡回の本文取得を有効にします。標準設定は変更しません。画像のスレタイ・URLフィルター、保存先、重複防止は維持します。本文の通信量も増える場合があります。[設定方法](patrol-images.md)
- 板のスレ一覧で更新ボタンを長押し、または新しい「既読スレをすべて削除」ジェスチャーから、取得済み・未読0件のスレを削除できます。確認画面で個別チェック／解除・全選択／解除し、選択した履歴とログを削除します。未読状態は削除直前にも再確認します。[操作・注意](delete-read-threads.md)
- 追加ツールバー4アイコンをMaterial Iconsのベクターへ統一しました。Haiagaru設定 → スレ・スレ一覧の表示 → ツールバー表示・追加アイコンから、表示オン／オフ、端末画像への変更、標準画像への復帰ができます。変更後は再起動してください。[詳細](toolbar-icons.md)
- 通常の返信画面からコマンドボタンを外しました。スレ立て画面では引き続き利用できます。

## 注意事項・検証範囲

既読スレの削除は元に戻せません。重要なログは先にバックアップしてください。アーカイブや保存レスは削除対象外です。掲示板上のスレは削除されず、板更新後に再表示される場合があります。

ビルド・3版へのパッチ適用・接続検査に加え、未読／履歴の242ネイティブ接続50項目、巡回フラグ48条件、絞り込み21項目を確認しています。アイコン・既読削除の確認画面は版別検証を実施しています。実サイトの起動時巡回による画像取得、実際の板でのジェスチャーからログ削除まで、タブレット左右ペインでの通し検証には未確認範囲があります。

正式版の取得先は1.7.1のまま変更しません。
