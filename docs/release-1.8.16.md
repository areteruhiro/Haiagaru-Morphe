# Haiagaru 1.8.16 — プレ版1.8.15からの変更

正式版とプレ版の取得先を同じ1.8.16のAndroid向けMPPへ更新します。1.7.1から更新する方は[正式版利用者向けのまとめ](release-1.8.16-from-1.7.1.md)もご覧ください。

## 対応版・導入前の注意

対応するChMateは **0.8.10.191 dev／0.8.10.226 dev／0.8.10.242 dev**。241／243 devは非対応です。元のChMate APKへ適用し、更新前にバックアップしてください。

「Change ChMate package name」のversionCode初期値を最大値 **2,100,000,000** に変更しました。同じパッケージ名・署名でパッチを当てる場合、対応版間の切り替えで低いコードが原因の上書き拒否を避けやすくなります。非対応版の互換化や署名違いの解消ではありません。元のコードを使いたい場合は適用前にオプションを解除してください。最大化後は低いコードのAPKを通常の上書きで戻せません。データを消すアンインストールは安易に行わないでください。

## ワッチョイ上／下4桁検索

- ツールバーとワッチョイ長押しから上／下4桁検索を呼び出せます。それぞれ設定で表示切替できます。
- 板の複数チェック・折りたたみ、カレンダー期間指定、続きから検索に対応。サイトや板によって検索できる範囲は異なり、すべての投稿の網羅は保証しません。
- 取得できた投稿者ページのスレ名と本文を表示。ZZZSearchはアプリ内Web表示から利用でき、外部ブラウザにも切り替えられます。
- 通知付きバックグラウンド検索を追加（初期オフ）。通知から戻る／停止ができます。OS制御で遅れる場合があり、プロセス終了後に自動再開はしません。
- 検索条件・結果を保存し、通信なしで開く／同じ条件で再検索を選べます。
- **履歴一覧から4桁・板・ID・スレ名・保存本文を検索**できます。履歴を選び「保存した結果の中を検索」を押すと、その回の保存結果だけを絞り込めます。大文字小文字を区別しない文字列検索で、空白区切りはAND条件です。追加通信は行いません。
- 保持件数・合計容量・1件の容量／結果数／文字数、ページキャッシュ容量・再利用時間を任意指定。**0で無制限／無期限**です。初期値は履歴20件・合計32MiB・1件2MiB、ページ16MiB・24時間再利用。省略・削除済みの結果は増量しても戻りません。
- MEGA／ローカルZIPの対象に「検索履歴・保存結果」と「取得ページキャッシュ」を個別追加（初期オフ）。設定も移す場合は設定カテゴリを選択してください。検索条件・本文を含むため取り扱いに注意してください。旧版は新カテゴリ入りZIPを復元できません。

詳しい操作は[4桁検索の案内](wacchoi-background-search.md)をご覧ください。通信間隔・応答サイズ等の安全制限は維持します。無制限でも空き容量・メモリ・OS上の限界は残ります。ZZZSearchのWeb結果はこの保存履歴には入りません。

## 人気レス・X・動画

- 人気レスを別ポップアップで表示する任意設定を追加（初期オフ）。独立閾値（初期3）で直接返信数を数えます。返信の連鎖は加算せず、同じレスからの重複アンカーは1件。暗色背景では白文字にし、行タップで元レスへ移動します。[操作](popular-replies.md)
- XプレビューのURL解析・本文再設定・完了通知・表示行更新を軽量化。カード形式と返信・リポスト・いいね・リンクコピー欄を追加。反応操作はX側のページで行い、自動投稿しません。[詳細](x-post-preview.md)
- 内部動画ビューアに0.5〜2倍の速度切替と画面長押し中だけ2倍速を追加。YouTube等すべての再生方式に同じ操作が使えるわけではありません。[詳細](video-viewer-controls.md)

## 保存・表示・修正

- スレッドアーカイブをスレ作成日時／保存ファイル更新日時の新しい順・古い順で表示可能に。作成日時不明のものは末尾へ。ファイル更新日時はコピー・復元で変わる場合があります。
- エッヂの次スレ検索にタイトル変更後の関連候補を追加。
- 全期間の閲覧履歴整理で、時刻不明の古い履歴も対象へ。
- 追加レスメニューの配置順と242のワッチョイ表示設定、書き込みメニュー追加項目の個別表示を調整。
- 既読スレ削除ジェスチャーの画面検出、投稿者強調による不要な再レイアウト、Kyodemoのテーマ表示を補正。
- ゼロ埋めで改行が失われた復元DAT行を補完し、特定条件で「未読1」が残る問題に対処。元DATとレス番号を維持します。未読不整合すべての解決ではありません。
- Talkのレスポップアップ領域を広告余白削除から除外。初回取得時の画面復帰Intentも補正。
