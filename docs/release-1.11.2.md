# Haiagaru 1.11.2

## 追加ライブラリの選択を改善

Image NG用ZIPと画像取得VPN用ファイルを取り違えると、`arm64-v8a/libgojni.so` がないという分かりにくいエラーになっていました。実機XIG05のMorphe 1.35.0で、VPNパッチの適用段階でこのエラーが出ていることを確認しました。

- ReleaseのAssetsへ、VPN専用の **haiagaru-image-vpn.zip** を追加しました。Image NG用の **haiagaru-image-ng.zip** とは別ファイルです。
- VPNパッチは新しいZIPと従来の **image-stack.aar** の両方を選択できます。どちらも展開不要です。
- オプション名・説明とファイル種類を間違えた場合のエラーを改善しました。必要な4 ABIのライブラリとSHA-256の検証は維持します。
- VPNが不要ならVPNパッチのチェックを外してください。Image NGの修正だけならVPNファイルは不要です。

[ダウンロード先と選択手順](optional-assets.md)

## 確認したこと

新ZIP・従来AARの4 ABI、Image NG用ZIP、ファイル種類の取り違えとハッシュ不一致の拒否をコマンドで確認しました。191元APKへ両ZIPを指定した適用・再構築・署名に成功し、生成APK内の両ライブラリとVPN導入マーカーも照合済みです。アプリ側の拡張DEX3本は1.11.1と同一ハッシュで、今回の変更は配布・選択・案内に限られます。修正後の実機Morphe操作は未確認です。

この変更はファイル配布・選択・エラー案内の修正です。VPNの全通信経路の検証完了や、実機でのVPN画像取得成功を示すものではありません。
