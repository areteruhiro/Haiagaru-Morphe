# スレ立てコマンド

対応: ChMate 191 dev / 226 dev / 242 dev。

スレ立て画面の本文付近に「コマンド」ボタンを追加。返信画面には表示しません。
投稿先のURLにより5ch・エッヂの候補を切り替えます。その他は自由入力のみです。
候補を選択して編集し、「本文に追加」で先頭に追加します。自動送信はしません。
ワッチョイ候補（IP／レベル付きも含む）の初期値は同じコマンド3行です。投稿時に1行消費される場合の次スレ用に残せます。自由入力を含め改行可能で、4096文字まで入力できます。
編集内容は掲示板サービス・候補ごとに端末内へ保存し、「初期値」で戻せます。
同じ内容は再度追加できます。異なる設定の同系統コマンドが本文や入力内にあれば編集を案内します。古い1行の初期値を保存していた場合は3行に移行し、独自に編集した内容は保持します。「初期値」で3行に戻すこともできます。

5ch: ワッチョイ / ワッチョイ＋IP（公開に注意）。
エッヂ: ワッチョイ / ワッチョイ＋レベル / レベル。
掲示板の設定・実装によってコマンドが無効な場合があります。
