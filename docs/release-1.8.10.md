# Haiagaru 1.8.10 (Pre-release)

1.8.9から、複数の「保存用スレ」とその閲覧機能、226 devのタブ選択補正を追加しました。
対応: ChMate 0.8.10.191 dev／0.8.10.226 dev／0.8.10.242 dev。

## 好きなレスを保存用スレへまとめる

レス本文を長押し →「このレスをアーカイブに保存」→「新しい保存用スレを作成」から、名前付きの保存先を作れます。
保存先は複数作成でき、別の元スレのレスも同じ保存用スレへまとめられます。同じレスを別の保存用スレへ保存することも可能です。

「過去レスを見る」から保存用スレを選ぶと、名前・日時・本文・元URLをオフラインで続けて閲覧できます。
1ページ10レスずつ表示し、長い本文はタップで全文表示。名前変更と、確認付きのレス削除にも対応します。
端末内だけの保存・閲覧機能であり、掲示板へのスレ立てや投稿は行いません。

191 devの通常のレス長押しで保存項目が出ない経路を修正しました。226／242 devも対応します。
従来の保存レスは「従来の保存レスを見る」に残り、元のDAT・既読位置・スレ単位のアーカイブは変更しません。

## MEGA・ローカルバックアップにも保存

バックアップ対象の「レスのアーカイブ・保存用スレ」を選ぶと、保存用スレの名前・保存したレスがまとめて含まれます。
新規設定では初期選択済みですが、既存のバックアップ対象設定は維持するため、選択状態を確認してください。
復元後は「過去レスを見る」から読み直せます。画像・動画ファイル自体は保存しません。

MEGAはパッチ導入時に「MEGAバックアップ・同期」の選択が必要です（Android 7.0以降）。
MEGA未導入でもローカルバックアップ・復元は利用できます。
バックアップにはレス本文などが含まれるため、保存・共有先に注意してください。

## 226 dev：タブレットモードの選択位置を補正

タブ一覧の更新中に、途中のページ選択がモデルへ書き戻される可能性を抑えました。
タブを閉じてから新しいスレを開いた際の、選択位置のずれへの対策です。
元のタブ追加・削除・並び順は維持し、例外時も元の状態へ復帰します。他版のタブ処理は変更しません。
