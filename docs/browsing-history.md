# 閲覧履歴を板ごとに表示

対応：ChMate 0.8.10.191 dev／0.8.10.226 dev／0.8.10.242 dev。1.8.11。

「Haiagaru設定 → 履歴・保存件数」に「閲覧履歴を板ごとにまとめる（通常画面のみ）」を追加しました。初期値はオンです。

- 通常画面の「履歴」を、最近閲覧した板から順にまとめます。各板の中も閲覧が新しいスレから表示します。
- 板名や日付の区切り行は追加せず、スレだけを連続表示します。同じ板名でもホストが異なる板は別に扱います。
- 対象は初期値で「2日前の午前0時から今日まで」です。端末の現地時刻を使います。例えば10月17日なら10月15日午前0時以降です。
- 「まとめる閲覧履歴の対象」で1〜36500日前を指定できます。0なら全期間です。期間外は表示から除くだけで、履歴やDATは削除しません。
- オフにするとChMate従来の履歴表示へ戻ります。設定変更時は既存の履歴設定と同じくアプリを再起動して反映します。
- ポップアップの「最近見たスレ」、お気に入り、未読一覧、書き込み履歴の並び順・件数は変更しません。

履歴自体がChMateの自動整理で削除されている場合、この設定では復元できません。必要なら別項目の保存数／自動削除設定も調整してください。

## 実装境界

191／226は通常ホームのネイティブ並べ替え完了後、表示コピーとフィルター用コピーを更新します。DBから読み込んだ全履歴モデルは変更しません。242は通常ホーム専用のAdapterData生成時、閲覧履歴モード103に限ってリストを差し替えます。ポップアップの生成処理にはフックしません。

### 未読一覧への誤適用修正（1.8.13）

HOMEのネイティブIDは101が未読、103が閲覧履歴、104が書き込み履歴です。1.8.11の実装と接続テストで101を閲覧履歴と誤認していました。判定を103へ訂正し、未読一覧では標準の並び順・件数・区切りをそのまま保持します。設定値の変更や履歴DBの修復は不要です。

修正後の確認：Androidビルド、3版へのパッチ適用・DEX接続検査、並び順・日付12項目、エミュレータの242ネイティブ行／AdapterDataを使った50項目に合格。101／-101など7モード×5パターンについて入力リストの参照・順序・件数が維持されることを検査しました。191／226は同じ共通判定の修正で、今回の実行時再検査は242のみです。ジェスチャーフックの引数保持も修正し、最終ビルドでHOME起動を確認しました。実機での一覧並べ替え操作は未確認です。
