# Haiagaru 1.9.0

正式版1.9.0を公開しました。正式版・プレ版の取得先を同じ1.9.0へ更新しています。対応はChMate 191 dev／226 dev／242 devです。

- **正式版1.7.1をご利用の方:** [追加機能・変更点・注意事項](https://github.com/areteruhiro/Haiagaru-Morphe/blob/master/docs/release-1.9.0-from-1.7.1.md)
- **プレ版1.8.15をご利用の方:** [今回の差分・操作案内・確認範囲](https://github.com/areteruhiro/Haiagaru-Morphe/blob/master/docs/release-1.9.0.md)

ワッチョイの四文字必須解除、Kyodemo経由のエッヂID・スレ名・レス本文検索、走査上限10,000・通信回数上限、検索履歴とバックアップ、追加機能の個別表示、設定内ジェスチャー、記者IDの表示先選択、人気レス、X軽量化、動画の速度・直接URLサムネイル等を収録しました。

更新前にバックアップし、元APKへ再度パッチを適用してください。versionCode最大化（2,100,000,000）が初期有効です。低いコードのAPKへ通常上書きできなくなるため、必要なら適用前に解除してください。241／243 devは非対応です。

任意・開発中機能を含み、全端末・全機能の通し確認は未完了です。動画の端末依存クラッシュ、Talkのタップ／「進む」復帰等の残存報告も各案内に記載しています。

配布物 `haiagaru_patches-1.9.0.mpp` と `patches-1.9.0.mpp` は同一のAndroid向けMPPです。Morpheへ登録済みの方は配布元を更新してください。

ご報告・検証・ご支援ありがとうございます。継続開発の応援は[READMEの寄付案内](https://github.com/areteruhiro/Haiagaru-Morphe#寄付)とGitHubのStarをご検討ください。
