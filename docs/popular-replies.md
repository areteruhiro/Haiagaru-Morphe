# 人気レスのポップアップ（直接返信方式）

Haiagaru設定の「スレを読む」にある「人気レスを直接返信数で判定し、ポップアップで表示」をオンにします（初期オフ）。「人気レスの直接返信数の閾値」で1〜9999を指定できます（初期3）。

オンの間、上部の「人気レス」またはツールバーのフィルタ内「人気レス」を押すと、読み込み済みレスから直接返信数が閾値以上のレスを別のダイアログに表示します。閉じても元のスレの表示位置・フィルタ・既読数を変更しません。追加の通信や未取得レスの取得はしません。

`>>1` に3つの異なるレスが直接返信していればレス1は3件です。それらの返信にさらに返信が付いてもレス1へ加算しません。同じレスが `>>1` を繰り返しても1件です。範囲・カンマ区切りアンカーも読み込み済みの過去レスだけを対象にします。表示順は元のレス順です。

オフでは標準の人気レス抽出を使用します。この追加設定の閾値はChMate標準の閾値と独立です。チンクル内部と同じ実装の保証ではなく、直接返信だけを数える方式です。

暗い背景では白文字で表示します。レスの行をタップした場合だけ、元スレ内の該当レスへ移動してポップアップを閉じます。NGや他のフィルタなどで表示対象にないレスは、条件を勝手に解除せず移動できない旨を表示します。本文変換・集計はバックグラウンドで行います。
