# 長いスレと手動サムネイルの表示負荷（修正候補）

報告条件は191系のスレ表示、サムネイルの手動ダウンロード設定です。
対象スレ: https://bbs.jpnkn.com/test/read.cgi/jptta45/1792405672/
読み込み時の枠と表示崩れは自然に消え、手動設定では特にカクつくとの報告です。

## コードから確認した負荷と修正

- 同じレスの添付URL取得が、計測・再バインド時にも本文のURL解析を繰り返していました。
  本文と画像／動画取得設定が一致する場合は、弱参照キーのレス単位キャッシュで解析結果を再利用します。
  保持上限は4096件です。本文や取得設定が変われば再解析します。
- Twimg画像／X動画／Imgur動画／一般動画の添付候補をまとめて反映します。
  最終的なURL配列の順序・内容が同じなら、サムネイル用の派生キャッシュを破棄しません。
- メタ情報の解決結果で実際に添付URLが変わった場合だけ一覧更新を要求します。
  連続する完了通知と動画キャッシュ更新を各80ミリ秒の単位でまとめます。
  非表示の一覧は再通知の対象から外します。

191の本体コードでは`notifyDataSetChanged`がレス表示キャッシュの世代を更新し、
再バインド時に行の`requestLayout`も呼びます。拡張からの更新通知が連続すると、
この本体処理も繰り返し実行されます。

URL解析キャッシュは取得結果そのものを固定しません。非同期で解決したメタ情報、
後から生成された動画サムネイル、取得設定の変更は引き続き反映します。
