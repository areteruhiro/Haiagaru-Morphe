# 設定例：NGWordに一致した投稿者の別レスと、その返信も連鎖NGにする

目的は「NGWordに一致した投稿者Aの別レスに返信したB、そのBに返信したCもNGにする」です。1.11.0から高度なNGのAPI v2で指定できます。標準NGWordの登録済みの語句を使う場合は、後半の標準NGの方法も利用できます。

## 高度なNGを使う場合（1.11.0以降）

1. Haiagaru設定 →「NG・ミュート」→「高度なNGルール（条件・スクリプト）」を開きます。
2. 「NG条件を追加」→「キーワードに一致した投稿者・返信を連鎖NG」を選びます。
3. 判定対象は「レス本文」にし、適用する板を選びます。判定式の `NGワード` を自分の条件に置き換えます。
4. 「直近のデータでテスト」で確認し、「一覧に反映」を押します。全体と個別ルールを両方オンにし、一覧の「保存」で確定します。対象スレを開き直してください。

```javascript
function (text, options) {
  return {
    match: text.includes("NGワード"),
    samePoster: true,
    chainReplies: true
  };
}
```

[配布用JavaScript](../presets/advanced-ng/word-author-replies.js) ／ [Releaseからダウンロード](https://github.com/areteruhiro/Haiagaru-Morphe/releases/download/1.11.0/word-author-replies.js)

`match` が起点の条件、`samePoster` がその投稿者の別レス、`chainReplies` が起点と別レスへの返信・孫返信です。条件を正規表現やIDとの組み合わせに変えることもできます。返信した別人の他のレスまでIDで追加する動作ではありません。

このスクリプトは標準NGWordの登録語句を自動で読み取りません。既存の登録語句をそのまま使いたい場合は次の方法を選んでください。従来の `true`／`false` ルールも使用できます。

## 標準NGWordを使う場合（1.10.0以降）

1. ChMateのNG設定からNGWordを追加します。
2. 例として `NG連鎖確認用ワード` を文字列として登録し、「有効」をオンにします。
3. **同じNGWordの項目で**「連鎖」と「投稿者のIDもNG」を両方オンにします。
4. 対象板を指定して保存し、対象スレを閉じて開き直します。実際の利用時は例の語句を自分のNGWordへ置き換えます。

## 判定例

| レス番号 | ID | 本文 | 期待する結果 |
| --- | --- | --- | --- |
| 10 | ExampleA | NG連鎖確認用ワード | NGWordに一致 |
| 20 | ExampleA | 別の本文 | 10と同じ投稿者なのでNG・連鎖の起点 |
| 30 | ExampleB | `>>20` への返信 | 連鎖NG |
| 40 | ExampleC | `>>30` への返信 | さらに連鎖NG |
| 50 | ExampleD | 関係のない本文 | この条件ではNGにしない |

表は説明用です。掲示板へ確認用レスを投稿する必要はありません。「非表示」の設定によっては、NG対象があぼーん表示ではなく一覧から隠れます。

## 高度なNGルールとの関係

API v2のスクリプトは判定中の1レスを起点として返し、拡張側が同じスレの取得済みレスから投稿者と返信をたどります。板をまたいでIDをまとめず、表示フィルターがある場合は利用できる元一覧を参照します。未取得のレスへの参照は次の読み込み時に再計算します。IDなしやシステムIDを同じ投稿者としてまとめません。

標準NGの方法は高度なNG全体がオフでも動作します。高度なNGの方法は全体と個別ルールの両方がオンの場合に動作します。どちらも標準NGIDの保存一覧やDATへ追加・変更を行いません。オフにしてスレを開き直すと、その機能による追加判定が解除されます。他のNG条件による非表示は残ります。

「連鎖」だけのルールと「投稿者のIDもNG」だけの別ルールを組み合わせた場合は対象にしません。IDなしレス、無効なルール、強調表示だけのルールは除外します。まだ取得していないレスは判定できません。
