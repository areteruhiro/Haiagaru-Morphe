# 書き込み画面の文字サイズ

対象: 0.8.10.191 dev / 0.8.10.226 dev / 0.8.10.241 / 0.8.10.242 dev。

Haiagaru設定の「書き込み画面の文字サイズ」で標準、10〜36spを選択可能。
「その他（任意のサイズ）」では1〜200spを小数も含めて入力できる。
無効な入力では設定を保存せず通知。旧版の整数設定は引き継ぐ。
標準ではChMateのサイズを変えない。spなので端末の文字拡大設定も反映される。
書き込み画面内の本文・名前・メール・新規スレタイのEditTextにのみ適用。
閲覧画面、ボタン、プレビューの文字サイズには影響しない。

全版共通のResEditActivity.onResume終了時に適用し、Fragment追加に備えて
メインキューでも一度適用する。文字列、選択、Cookie、送信処理は変更しない。
初期サイズは弱参照で保持し、標準に戻した際に復元。倍率の累積は発生しない。
設定保存後、次に書き込み画面を開く／復帰した時点で反映する。

VerifyPostEditorTextSize.javaで生成APKの拡張クラス・設定getterと、
書き込み画面だけへのonResumeフックを検証する。
