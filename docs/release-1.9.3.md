# Haiagaru 1.9.3

## ツールバーの表示チェック

191／226／242で、追加アイコンの生成時に標準のチェック状態をHaiagaru側で上書きしていた処理を廃止しました。226／242ではチェック切替で項目をコピーするため、外した直後にチェックが戻る原因となっていました。191では設定の読込時に同じ上書きが起きていました。

HOME・スレ一覧・スレッドの各ツールバーで、標準の表示チェックと配置順を保持します。Haiagaruの「ツールバー表示・追加アイコン」がオンなら標準側のチェックに従い、オフなら描画時だけ全体の表示を抑えます。対象はエッヂ過去ログ、フィルタ、未読をすべて0、長押しコピー、ワッチョイ上／下4桁検索です。★スレのみ巡回は変更対象外です。

標準ツールバー設定からチェックを変更してください。Haiagaru側の全体設定を変更した場合は、従来どおり再起動後に反映します。

## コピペ省略2

設定を切り替えても、開いているスレの省略判定へ反映するための再起動案内が出ない問題を修正しました。変更後は再起動を選んでください。再起動前にChMate標準設定の保存完了も確認します。標準の判定条件と設定OFF時の分岐は維持しています。

## ローカルバックアップ

- 保存先フォルダを選んだ直後、開いた設定画面へ反映します。同期保存に成功してから完了を表示します。
- 保存先のURIをそのまま表示せず、デコード済みのフォルダ名を表示します。日本語の名前がパーセント表記になる問題を修正しました。アクセス用URIは保持します。
- 同じフォルダを選び直しても、前回成功日時や保存済みZIPの管理記録を初期化しません。
- ローカル復元の初期チェックを、そのバックアップに保存された項目へ合わせます。現在の端末の保存項目設定には左右されません。
- 「内容・注意事項」を開いて戻っても、変更した復元項目のチェックを保持します。復元の実行・機密情報の確認は従来どおり必要です。

## 対応と確認範囲

ChMate **191 dev／226 dev／242 dev** 対応。Android向けMPPビルドと3版へのパッチ適用が成功しています。今回の修正について、端末でのコピペ省略表示、ツールバー操作とフォルダ選択・保存・復元の通し確認は未実施です。

元APKへ再パッチし、同じパッケージ名・署名で更新してください。データ削除・初期化は不要です。
