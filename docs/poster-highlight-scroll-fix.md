# 投稿者の個別色とスクロールの補正

強調設定更新時、表示中のTextViewを `setText` で作り直したうえで、Xプレビュー用のスクロール位置復元処理を呼んでいました。スクロール中の位置変更や再レイアウトを招く経路を除去しました。報告された間欠的な症状そのものの発生条件は未確定です。

- 変更できるSpannableは、その場で強調用のspanだけを更新します。
- 個別の色だけを変えた場合は太字spanを維持します。既存のネイティブspanも維持します。
- 強調結果が同じならspanも作り直しません。
- 強調更新からスクロール位置の復元を呼びません。
- 投稿者の判定に使わない本文全体のスナップショットと、スレ主ルール未使用時のスレ主解析を省きました。

191／226／242共通の拡張処理です。エミュレータの実Android TextView／Spannableで59項目を確認し、各バージョンの投稿者モデルについて2件登録・個別色・同じTextViewへの100回再適用・ネイティブspan維持を検証しました。通常の色変更でTextWatcherの本文変更通知が発生せず、文字列オブジェクトと太字spanが維持されることを確認しています。
