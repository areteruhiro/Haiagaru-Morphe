# ワッチョイ下4桁で検索

対象: ChMate 0.8.10.191 dev / 0.8.10.226 dev / 0.8.10.242 dev。

ワッチョイ長押しメニューの「ﾜｯﾁｮｲ下4桁で検索」を押すと、現在の板を対象にKyodemo検索を開きます。
例: `ｽｯﾌﾟ Sd03-uDul` → 検索語 `-uDul`。
キャリア名・前半4文字は渡さず、大文字小文字や `+`・`/` などの記号は保持します。
既存の「ﾜｯﾁｮｲで検索」は従来どおり全体を検索し、「下4桁をNG登録」の動作も変更しません。

下4桁を取得できないワッチョイや、Kyodemoの検索対象外の板には項目を追加しません。
検索結果はKyodemoの収集範囲・検索仕様に依存します。
専用ビューアを使わない設定の場合は、既存と同様にChMate標準のWeb表示で開きます。
