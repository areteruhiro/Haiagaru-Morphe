# NG編集のジェスチャー割り当て

対象: ChMate 0.8.10.191 dev / 226 dev / 241 / 242 dev。

ChMateの「設定 → ジェスチャー → 割り当て」に「NG編集」を追加する。
初期値は未割り当て（0）。ChMate標準のジェスチャー入力ダイアログで登録・変更・解除できる。
実行するとChMate標準のNG編集画面を開く。NG条件の追加・変更は行わない。
既存の操作と同じジェスチャーを設定した場合は既存の操作を優先するため、未使用のものを割り当てる。

## 実装

- ジェスチャー設定XMLの「設定」の次に標準GesturePreferenceを追加。
- ネイティブのジェスチャー完了処理の、フォーカス・ライフサイクル確認後に処理を挿入。
- 未割り当て・別のジェスチャー・非表示のViewはネイティブ処理を継続。
- 242では全ローカルレジスタが使用中なので、検索先のレジスタを一時利用して元に戻す。レジスタ数は変更しない。
- NGEditorActivityは標準同様startActivityForResultのrequestCode=0で起動する。
- 専用ビュワーのスワイプ設定は変更しない。

## ジェスチャー中の案内文字（1.8.7公開後の修正）

1.8.7ではNG編集の完了処理だけを追加していたため、ジェスチャー中の標準描画処理が
参照する操作データがなく、「NG編集」の文字が出なかった（226 devで報告）。

- 191 / 226 / 241 / 242の標準`dispatchDraw`で、操作の検索結果がない場合だけ
  `NgEditGesture.preview`を呼び、対象のネイティブ型の表示データを補う。
- 文字の位置・サイズ・色・縁取りはChMate標準の描画に任せる。
- 未割り当て・別のジェスチャー・既存の割り当てとの競合では補わない。
- 表示用データは登録表に追加せず、標準リスナーへ独自操作IDを流さない。
  NG編集を開く既存の完了フックと全体オン／オフの処理は維持する。
- 表示データはViewの型・設定ジェスチャー単位で再利用する。

検証用スクリプト：`frida-ng-label226-test.js`（隔離したエミュレータ用APK限定）。
実際の226ネイティブViewを使い、表示文字・型、未割り当て・競合・既存操作優先、
標準描画結果の差分と登録表を変更しないことを確認する。
