# NG編集のジェスチャー割り当て

対象: ChMate 0.8.10.191 dev / 226 dev / 241 / 242 dev。

ChMateの「設定 → ジェスチャー → 割り当て」に「NG編集」を追加する。
初期値は未割り当て（0）。ChMate標準のジェスチャー入力ダイアログで登録・変更・解除できる。
実行するとChMate標準のNG編集画面を開く。NG条件の追加・変更は行わない。
既存の操作と同じジェスチャーを設定した場合は既存の操作を優先するため、未使用のものを割り当てる。

## 実装

- ジェスチャー設定XMLの「設定」の次に標準GesturePreferenceを追加。
- ネイティブのジェスチャー完了処理の、フォーカス・ライフサイクル確認後に処理を挿入。
- 未割り当て・別のジェスチャー・非表示のViewはネイティブ処理を継続。
- 242では全ローカルレジスタが使用中なので、検索先のレジスタを一時利用して元に戻す。レジスタ数は変更しない。
- NGEditorActivityは標準同様startActivityForResultのrequestCode=0で起動する。
- 専用ビュワーのスワイプ設定は変更しない。
