# 外部板のスレ情報ポップアップ

## 差分

- ふたば・爆サイ・あにまんのスレ情報ポップアップで、仮想スレ番号をUnix時刻として表示する経路を191・226・242で補正。従来のスレ一覧日時フックとは別のDateUtils呼び出しだったため、既存修正が届いていなかった。
- 登録済みgatewayのhost/port/板キーを厳密に照合し、その板・スレの作成日時キャッシュ、なければ保存済みDAT先頭行（最大4KiB）を使用。日時不明の場合は「日時不明」。他板・通常のChMate URLの日時を変更しない。
- 同じポップアップの板名はgatewayの登録名から取得。あにまんは既知の所属カテゴリが登録・有効ならカテゴリ名を使用。
- あにまんの本文ページの正規URLとパンくずから所属カテゴリを確定して保存。一覧から消えたスレでも一覧を検索する必要がない。新しいカテゴリはページで確認できたURLと名前で登録し、既存の無効なカテゴリは有効にしない。
- ポップアップからの板移動はBBSUrlInfoの汎用生成URLをそのまま渡さず、登録板のgateway URLを使う。カテゴリ不明・無効なら元の登録板へ戻す。
- スレ一覧の板情報がない場合のタイトルも登録名で補完。URL生成・保存済みスレID・板ID・履歴・既読・NG・ログのキーは変更しない。
- あにまんのrootがホスト名やURLとして保存されていた場合の既定名を「あにまん」とする。利用者が付けた別名は保持。
