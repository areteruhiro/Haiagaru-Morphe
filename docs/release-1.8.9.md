# Haiagaru 1.8.9 (Pre-release)

1.8.8に含まれていなかった外部板の認証支援と、登録した外部板の名前・URL編集を追加しました。1.8.8の機能は引き続き利用できます。

対応: ChMate 0.8.10.191 dev／0.8.10.226 dev／0.8.10.242 dev。

## 外部板の認証ページをアプリ内で開く

書き込み画面の「︙ → 外部板の認証ページ」から、板が案内する認証ページを開けます。「Haiagaru設定 → 詳細 → 外部板の認証ページを設定・開く」でも設定できます。

認証後に「認証を反映して戻る」を押すと、その板のHTTPS通信にCookieを連携します。書き込みエラーが認証を要求している場合も案内します。二重投稿防止のため自動再投稿は行いません。内容を確認して手動で再送信してください。

認証コード入力やCAPTCHAは利用者が操作してください。Cookie以外のトークン・端末認証やWebViewを許可しないサイトでは利用できない場合があります。

## 登録した外部板の名前・URLを編集

「ChMate設定 → 掲示板／BBSMENU → 登録した外部板の名前・URLを編集」から変更できます。変更後はアプリを再起動してください。

ブックマーク・過去ログ・NGの識別情報は維持します。同じ板の名称変更・移転向けです。別の板への付け替えには使わないでください。移転先への認証情報のコピーは行いません。必要なら再認証してください。

## 修正と検証範囲

- パッケージ名変更時に、追加設定の起動先が元アプリのままになる問題を修正。
- 191／226／242で板URL変換・識別情報維持、認証Cookie連携を検証。191では画面からの編集・保存・再起動後の反映、242では標準設定からの画面起動も確認。
- 実サイトの認証コードによる認証完了・投稿成功は未検証です。すべての外部板の認証方式に対応するものではありません。
- 詳細: [外部板認証](https://github.com/areteruhiro/Haiagaru-Morphe/blob/dev/docs/external-board-auth.md)／[板名・URL編集](https://github.com/areteruhiro/Haiagaru-Morphe/blob/dev/docs/external-board-editor.md)

プレリリースのため、重要なデータは事前にバックアップしてください。正式版の取得先は変更しません。
