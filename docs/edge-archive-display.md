# エッヂ過去ログ検索の表示設定

検索画面右上の「表示」から設定します。191 dev／226 dev／242 devで共通です。

- 「検索欄・操作ボタン」: スレタイ入力、検索、詳細条件、ページ送りなどの文字を70～150%に調整。
- 「検索結果」: 結果のスレタイ・日時の文字を別に70～150%に調整。
- 「検索欄を隠して結果を広く表示」: 入力欄と検索・詳細条件を折りたたみ、結果に表示領域を割り当てます。「表示」から解除できます。
- 「標準に戻す」: 両方100%、検索欄を表示に戻します。

設定は次回起動時にも保持します。適用しても検索条件・取得済みの結果は消さず、再検索もしません。
端末のフォント倍率も反映されます。元サイトのWeb表示の設定とは別です。
