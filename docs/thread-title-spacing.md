# スレ一覧タイトルの行間（未公開修正）

対象：0.8.10.191 dev / 226 dev / 241 / 242 dev。

旧実装は105%以上で `includeFontPadding` を強制的にオンにしていたため、
スレタイ上側と区切り線の間に、設定値によらない一定の余白が発生していた。
また、TextViewの行間倍率は日本語のフォールバックフォントの計測に影響されるため、
外側の余白だけ変わり行間の差が分かりにくい場合があった。

修正では標準のフォント余白・View余白・行間倍率を変更せず、タイトル本文に専用の
`LineHeightSpan` を付け、各行の実際のフォント計測値に対する追加間隔を設定する。
先頭行の上端と最終行の下端は変更しない。1行だけのタイトルは高さを変更しない。
105% / 110% / 150% / 200% に応じて、折り返し行のベースライン間隔のみを広げる。

- 100%に戻す場合は独自Spanのみ取り除く。リンクや検索強調などの既存Spanは保持する。
- 再バインドでSpanを重ねない。
- AndroidがFontMetricsIntを行ごとに再利用する場合は前行への追加分を戻し、間隔の累積を防ぐ。
- `scripts/VerifyThreadTitleSpacing.java` で割合、再適用、標準復帰、既存Spanの保持、
  計測値再利用、最終行を検査する。
- `scripts/frida-title-spacing-test.js` は分離した検証アプリ限定でAndroidの実際のTextViewを
  使い、3種のフォント、折り返し位置、先頭行位置、外側余白、全行の均一な間隔、
  行数に比例した高さ、1行タイトル、100%への復帰を検査する。

検証：AndroidバンドルビルドとJava回帰テストに成功。
191 / 226 / 241 / 242への最終修正版パッチ適用と、APK内のタイトル専用フック・
行間Span・外側余白を変更しないことの静的検査に成功。
191 / 242の分離アプリで、AndroidのTextViewを使う366項目の描画計測テストがそれぞれ成功。
105% / 110% / 150% / 200%と100%への復帰、3種の標準フォント、フォント余白の両設定を確認。
ユーザー独自のカスタムフォントそのものは未検証。
ログ：`build/verification/title-spacing191-verified-runtime.log`、
`build/verification/title-spacing242-verified-runtime.log`。
