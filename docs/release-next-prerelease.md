# Haiagaru プレリリースの変更内容

いつも不具合の報告やご提案をありがとうございます。今回は、必死チェッカーの日本語表示と人気レスの判定設定を改善しました。これまでの変更内容と確認範囲も以下にまとめています。

## 今回の主な変更

- 人気レスの件数が「—」になる経路と、「自分」フィルターが自分の投稿を見落とす判定を修正しました。人気レスの実スレ確認では標準方式126件／直接返信方式1件、直接返信・ポップアップ設定の4通りを切り替えて負数や失敗がないことを確認しました。「自分」は実データで1件を抽出できることを確認しています。
- 「新着があるのに更新なし」となる問題への検証用対策を追加しました。191／226／242 devのDAT取得で古い条件付き応答を避けつつ、部分取得（Range）は維持します。ただし、新着レスがある状態を再現した通し確認はできていません。今回の下書きは検証用です。通信量や更新結果を確認してから通常公開してください。
- HOME履歴のDAT落ち非表示は、URL不正や古い履歴データが混じっても、他の履歴の判定を止めないようにしました。設定OFFで元の表示へ戻り、履歴データや本体のDATフラグを変更しないことを確認しました。

- 必死チェッカーで日本語が文字化けする問題を修正しました。Hissi側の文字コード表記が食い違う場合も、受信した内容を判定して表示します。対象は専用ビューア内のHissiページです。
- 人気レスの判定方法と表示方法を別々に設定できるようになりました。ChMate標準の通常／ツリー判定を使うか、直接返信数で判定するかを選べます。ポップアップ表示も独立してオン／オフできます。以前の設定は引き継ぎます。
- 画像取得用VPNライブラリを `haiagaru-image-vpn-v2.zip` として配布します。以前のパッチ用に従来名のZIPも残します。VPNパッチは任意で、初期状態では有効になりません。
- HOMEの履歴で「DAT落ちスレを非表示」が有効になることを、191で再確認しました。提供された5chのスレも判定用データで確認しています。履歴行自体を実データで再現した試験ではないため、確認範囲の詳細は[記録](history-dat-hissi-encoding-20261022.md)をご覧ください。
- 人気レスは242の実スレで標準方式と直接返信方式を比較し、表示切替と件数を確認しました。指定されたPart3のスレ上での件数は確認できていません。詳しくは[検証記録](popular-reply-modes.md)をご覧ください。
- HOMEの履歴で「DAT落ちスレを非表示」が効かなくなる問題を修正しました。一部の履歴からURLを取得できない場合も、ほかのDAT落ちスレの非表示を続けます。同じスレの古い履歴データも、確認済みの判定を使います。履歴やログ自体は削除せず、設定をオフにすると再表示します。
- GIF動画の再生中に︙メニューを開くと、再生時間やコントロールの表示がおかしくなる問題を修正しました。
- 動画の「戻る／進む」ボタンが、操作設定の秒数に従うようになりました。5・10・15・30・60秒から選べます。ダブルタップを使わない場合も設定でき、ボタンの表示にもすぐ反映されます。
- フィルターのフローティングボタンを任意で表示できるようにしました。長押ししてドラッグすると位置を変えられ、次回も配置を引き継ぎます。初期状態は非表示です。従来の固定された右下ボタンは表示しません。
- 「VPN取得の対象ドメイン」の説明が入力欄と重なる表示を修正しました。

- エッヂ過去ログ検索の検索先に「Kyodemo（現行＋過去ログ）」を追加しました。従来の検索先が利用できない場合も切り替えて検索できます。検索先によって使える詳細条件は異なります。[検索先の違い](edge-archive-providers.md)

## 前回までの改善

- フィルターの「画像」を長押しした際、閉じる処理が操作を途中で中断する問題を修正しました。下部フィルターと、通常のダイアログの項目・ボタンにも同じ対策を広げています。
- タブレットの追加画面を、Haiagaru設定内の「画面を新しいタブに追加」から選べるようにしました。新規タブ画面の上に出していた独立ボタンは撤去しています。
- タブにできる画面を「投稿を探す」「投稿検索・結果（必死チェッカー／Kyodemo）」「ワッチョイ全文検索」にも広げました。画面ごとにオン／オフでき、検索条件・結果・スクロール位置をタブごとに分けます。
- タブ内のHaiagaru設定も、通常画面と同じカード表示に揃えました。「機能名・スイッチ」の下に説明をまとめています。
- 認証画面へ移る前に既存Cookieを引き継ぎ、ex0chのSessionIDと署名を別の値で置き換えない処理を追加しました。実サイトはメンテナンス中のため、CAPTCHA完了・投稿までは未確認です。

- XのGIF動画を標準プレイヤーが読み取れない場合、別のMP4解析・再生経路へ一度だけ切り替えます。ループ再生に対応します。
- レス参照や更新時に集中する表示補助処理を分散しました。「>>番号」の反応は引き続き確認中で、遅延がすべて解消したという変更ではありません。
- キャッシュ済みWebリンクカードを行の計測前に反映するよう調整しました。短いスレで更新後に位置がずれる問題への対策です。
- エッヂ過去ログの検索結果を、囲み枠から横線の区切りへ変更しました。
- 検索画面の「表示」から、結果の文字サイズと上下余白をそれぞれ変更できます。専用ビューア内の使い方案内は外し、Haiagaru設定へまとめました。
- 追加画面をタブレットの本体スレタブと同じ列へ開く任意設定を追加しました。初期状態はオフです。
- 191で追加タブを開いた後、画面を離れる際に落ちる問題を修正しました。
- 取り込み済みの自作テーマ一覧と、確認付きのテーマファイル単位削除を追加しました。画像素材や取り込み元は残します。
- 保存レスを開く項目を「保存済みレスを見る」に変更しました。保存データはそのまま使えます。
- ﾜｯﾁｮｲ上4桁NG、追加フィルターの個別表示、フィルター長押しによる選択解除を追加しました。
- HOME履歴のDAT落ち非表示では、除外後に空になった「○分前」の見出しも隠します。
- 非表示NGレスを表示上の未読件数から除く任意設定を追加しました。取得・NG判定済みのレスが対象で、既読位置は変更しません。
- 必死チェッカー上部の説明を整理し、高さ調整と設定画面の見やすさを改善しました。

## それ以前の主な変更

- 191でスレを表示するときの処理を軽くし、応答しなくなる問題への対策を追加しました。

- 投稿検索の履歴から停止位置を引き継いで走査再開。3件の並行走査と個別停止・再開、走査一覧、途中開始にも対応。
- 5chのワッチョイ検索は元板とHissiを、エッヂは対応する検索先を初期選択。
- 設定初回に最低限構成を案内。明示的にオンにした場合だけ適用。
- `.haiagaru` ファイルで表示・動作設定を共有・確認後に読み込み。Cookie・認証・接続キー・履歴・NGルールは含めません。
- 推奨3パッチでパッケージ変更時に起きるManifest属性の重複を修正。
- 191のDAT落ち非表示で内部リストの一部が未初期化のとき、他の表示リストも処理されなくなる問題を修正。
- ﾜｯﾁｮｲ下4桁NG追加の対象板を先頭へ移動。共通フォームの二重スクロール・選択状態・見出し・文字項目の長押しも改善。
- Kyodemo／必死チェッカー・認証画面のスクロールを改善。
- フィルター件数と追加項目の個別設定、横操作の競合対策、任意の下部パネルを追加。
- X／リンクカードの描画時、読書位置を不要に補正しないよう調整。
- エッヂ過去ログの検索欄・検索結果の文字倍率を独立してCompose表示へ反映。
- 折りたたみ端末判定をDPIからJetpack WindowManagerの折り目情報へ変更。判定できない場合は手動設定を維持。

## ご利用にあたって

### 高度なNGの例

以下は「レス本文」に設定するスクリプト例です。`NGワード`を実際に判定したい文字へ置き換えてください。標準NGWordの登録一覧を読み込むものではありません。必要に応じてコピーして利用してください。

```javascript
function (text, options) {
  return {
    match: text.includes("NGワード"),
    samePoster: true,
    chainReplies: true
  };
}
```

フローティングボタンは「ツールバーとフィルターの設定」で「下部フィルターパネルを使う」と「フィルターのフローティングボタンを表示」をオンにすると使えます。非表示でもツールバーからフィルターを開けます。他のアプリに重ねる権限は必要ありません。動画の移動秒数は、専用ビューアの「︙ → 操作設定」から変更できます。

履歴の非表示は対応する3版で確認し、GIFの再生・操作・秒数表示、浮動ボタンの移動・配置保存も確認しました。実際のスレから浮動ボタンで下部パネルを開く操作と、スレ本文・画像の表示も確認しています。共通処理の重複確認は一部省略しています。端末ごとの長時間利用は引き続き確認が必要です。

本体タブ表示は「Haiagaru設定 → アプリ・通信 → 基本設定」から選べます。「画面を新しいタブに追加」で、Haiagaru設定・エッヂ過去ログ検索・投稿を探す・投稿検索・結果・ワッチョイ全文検索を追加できます。すべてのダイアログがタブになるわけではありません。

検索結果の一時キャッシュは、端末や利用者によるキャッシュ削除で消えることがあります。残しておきたい結果は検索履歴も利用してください。検索先のメンテナンスや収録状況によって、見つからない投稿もあります。

確認の詳細は[公開前の確認一覧](release-readiness-20261021.md)をご覧ください。大量履歴・NG設定、タブのプロセス復元、短いスレの更新位置や端末ごとの長時間利用は確認を続けています。バックアップを取ってからお試しください。正式版の配布先は変更しません。
