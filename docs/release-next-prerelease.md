# Haiagaru プレリリースの変更内容

前回のプレリリースから、設定や検索の使い勝手を見直しました。画面を閉じたあと操作できなくなる問題や、追加画面の表示を中心に改善しています。ご報告ありがとうございます。

## 今回の主な変更

- フィルターの「画像」を長押しした際、閉じる処理が操作を途中で中断する問題を修正しました。下部フィルターと、通常のダイアログの項目・ボタンにも同じ対策を広げています。
- タブレットの追加画面を、Haiagaru設定内の「画面を新しいタブに追加」から選べるようにしました。新規タブ画面の上に出していた独立ボタンは撤去しています。
- タブにできる画面を「投稿を探す」「投稿検索・結果（必死チェッカー／Kyodemo）」「ワッチョイ全文検索」にも広げました。画面ごとにオン／オフでき、検索条件・結果・スクロール位置をタブごとに分けます。
- タブ内のHaiagaru設定も、通常画面と同じカード表示に揃えました。「機能名・スイッチ」の下に説明をまとめています。
- 認証画面へ移る前に既存Cookieを引き継ぎ、ex0chのSessionIDと署名を別の値で置き換えない処理を追加しました。実サイトはメンテナンス中のため、CAPTCHA完了・投稿までは未確認です。

- XのGIF動画を標準プレイヤーが読み取れない場合、別のMP4解析・再生経路へ一度だけ切り替えます。ループ再生に対応します。
- レス参照や更新時に集中する表示補助処理を分散しました。「>>番号」の反応は引き続き確認中で、遅延がすべて解消したという変更ではありません。
- キャッシュ済みWebリンクカードを行の計測前に反映するよう調整しました。短いスレで更新後に位置がずれる問題への対策です。
- エッヂ過去ログの検索結果を、囲み枠から横線の区切りへ変更しました。
- 検索画面の「表示」から、結果の文字サイズと上下余白をそれぞれ変更できます。専用ビューア内の使い方案内は外し、Haiagaru設定へまとめました。
- 追加画面をタブレットの本体スレタブと同じ列へ開く任意設定を追加しました。初期状態はオフです。
- 191で追加タブを開いた後、画面を離れる際に落ちる問題を修正しました。
- 取り込み済みの自作テーマ一覧と、確認付きのテーマファイル単位削除を追加しました。画像素材や取り込み元は残します。
- 保存レスを開く項目を「保存済みレスを見る」に変更しました。保存データはそのまま使えます。
- ﾜｯﾁｮｲ上4桁NG、追加フィルターの個別表示、フィルター長押しによる選択解除を追加しました。
- HOME履歴のDAT落ち非表示では、除外後に空になった「○分前」の見出しも隠します。
- 非表示NGレスを表示上の未読件数から除く任意設定を追加しました。取得・NG判定済みのレスが対象で、既読位置は変更しません。
- 必死チェッカー上部の説明を整理し、高さ調整と設定画面の見やすさを改善しました。

## 前回までの主な変更

- 191でスレを表示するときの処理を軽くし、応答しなくなる問題への対策を追加しました。

- 投稿検索の履歴から停止位置を引き継いで走査再開。3件の並行走査と個別停止・再開、走査一覧、途中開始にも対応。
- 5chのワッチョイ検索は元板とHissiを、エッヂは対応する検索先を初期選択。
- 設定初回に最低限構成を案内。明示的にオンにした場合だけ適用。
- `.haiagaru` ファイルで表示・動作設定を共有・確認後に読み込み。Cookie・認証・接続キー・履歴・NGルールは含めません。
- 推奨3パッチでパッケージ変更時に起きるManifest属性の重複を修正。
- 191のDAT落ち非表示で内部リストの一部が未初期化のとき、他の表示リストも処理されなくなる問題を修正。
- ﾜｯﾁｮｲ下4桁NG追加の対象板を先頭へ移動。共通フォームの二重スクロール・選択状態・見出し・文字項目の長押しも改善。
- Kyodemo／必死チェッカー・認証画面のスクロールを改善。
- フィルター件数と追加項目の個別設定、横操作の競合対策、任意の下部パネルを追加。
- X／リンクカードの描画時、読書位置を不要に補正しないよう調整。
- エッヂ過去ログの検索欄・検索結果の文字倍率を独立してCompose表示へ反映。
- 折りたたみ端末判定をDPIからJetpack WindowManagerの折り目情報へ変更。判定できない場合は手動設定を維持。

## ご利用にあたって

本体タブ表示は「Haiagaru設定 → アプリ・通信 → 基本設定」から選べます。「画面を新しいタブに追加」で、Haiagaru設定・エッヂ過去ログ検索・投稿を探す・投稿検索・結果・ワッチョイ全文検索を追加できます。すべてのダイアログがタブになるわけではありません。

検索結果の一時キャッシュは、端末や利用者によるキャッシュ削除で消えることがあります。残しておきたい結果は検索履歴も利用してください。検索先のメンテナンスや収録状況によって、見つからない投稿もあります。

確認の詳細は[公開前の確認一覧](release-readiness-20261021.md)をご覧ください。大量履歴・NG設定、タブのプロセス復元、短いスレの更新位置や端末ごとの長時間利用は確認を続けています。バックアップを取ってからお試しください。正式版の配布先は変更しません。

[初回案内・共有・履歴再開・NG操作の詳細](settings-sharing-history-resume.md)、
[検索／フィルターの詳細](search-filter-2026-10-20.md)、
[文字倍率／折りたたみ判定の詳細](archive-scale-fold-fix.md)をご覧ください。
スレや画像の表示、スクロール、設定画面の基本操作を確認しています。ただ、長時間使った場合も含めて、応答しなくなる問題が解消したかは引き続き確認中です。

もし同じ症状が出たら、直前に行っていた操作やエラーの内容を教えていただけると助かります。ご報告ありがとうございます。
