# Haiagaru 1.11.0

対応するChMateは191 dev／226 dev／242 devです。元の未改変APKへパッチを再適用して更新してください。設定・履歴の初期化は不要です。

## 高度なNGから投稿者・返信を連鎖NGにする

高度なNGのAPI v2を追加しました。キーワードなどに一致するレスを起点に、その投稿者の別レス、別レスへの返信、その先の連鎖返信までNGにできます。

Haiagaru設定 →「NG・ミュート」→「高度なNGルール」→「NG条件を追加」から「キーワードに一致した投稿者・返信を連鎖NG」を選びます。語句・対象板を変更し、全体と個別ルールをオンにして保存してください。[設定手順・判定例](ngword-poster-chain-example.md) ／ [配布用JavaScript](../presets/advanced-ng/word-author-replies.js) ／ [API仕様](advanced-ng.md)

従来の `true`／`false` ルールは引き続き利用できます。標準NGWordの登録済み語句を自動で使いたい場合は、同じNGWord項目の「連鎖」と「投稿者のIDもNG」を両方オンにする従来の方法を使えます。新しいスクリプトは登録語句を自動で読み取るものではありません。

## 判定の修正

- 226の高度なNGをスレ単位で再判定し、取得済みの別レスや返信へ展開できるよう修正。本文や起点の変更後に古い判定を残さないようにしました。
- 242の描画用NGフラグは元の結果へ書き込まず、追加判定を重ねたコピーとして返します。無効化後に高度なNGのフラグが残る問題を修正。
- 242で板を限定したルールが他のタブの板情報を使わないよう、取得結果の板情報へ接続。
- 191で任意のスレタイ情報が取得できない場合も、レス本文のNG判定を続けるよう修正。
- 連鎖の展開は同じスレの取得済みの元一覧で行います。返信した別人の他の投稿にはIDで広げません。参照数・時間の上限超過時は、その回の高度なNGを適用しません。

新APIの判定、従来ルールとの互換性、板・スレ分離、キャッシュ更新、範囲・重複・循環参照、上限超過後の復帰を含む563項目のローカルテストに合格しています。最終MPPから191／226／242へ適用・署名し、API36エミュレータ上の実コントローラーで計59項目、ZZZSearch・設定で9項目に合格しました。実際のCompose入力欄の小数用IME指定も確認しています。3版のAPK命令を元APKと比較し、復帰処理のレジスタ・分岐・初回読込の保持を確認しました。
