# 過去ログの自動DAT取得

対応: ChMate 191 dev／226 dev／242 dev。

Haiagaru設定の「自動DAT取得」をオンにすると、SS速報VIPのスレを開く際に、
現行datが取得できない場合は同じホストの過去ログdatを取得します。
既存キャッシュがある場合は通常のChMate表示を使います。タブレット表示にも対応します。
SS速報VIPのURLを5chや外部ミラーの取得経路へ送信しません。

例:

```text
http://ex14.vip2ch.com/test/read.cgi/news4ssnip/1464424549/
→ https://ex14.vip2ch.com/news4ssnip/kako/1464/14644/1464424549.dat
```

## DAT取得経路の変数

「自動DAT取得経路」のURLテンプレートに以下を使用できます。
既存の `dat|`／`kako|`／`itest|`／`auto|` の書式と、設定済みの経路は維持します。

| 変数 | 内容 | 上記スレの例 |
| --- | --- | --- |
| `{$server}` | サーバー名（先頭ラベル） | `ex14` |
| `{$host}` | ホスト名全体 | `ex14.vip2ch.com` |
| `{$bbs}` | 板ID | `news4ssnip` |
| `{$key}` | スレッドキー全体 | `1464424549` |
| `{$rand}` | ランダム文字列 | 取得ごとに生成 |
| `{$key:0:4}` | キーの先頭4文字 | `1464` |
| `{$key:0:5}` | キーの先頭5文字 | `14644` |

`{$変数名:開始位置:終了位置}` で任意の部分を取り出せます。
位置は0始まりで、終了位置の文字は含みません。例えば `{$key:4:10}` は `424549` です。
取り出した値をURLエンコードして埋め込みます。不正な位置・未定義変数の経路は取得に使用しません。

SS速報VIPの組み込み経路は次の形式です。5ch用の取得順序とは独立しています。

```text
dat|https://{$host}/{$bbs}/kako/{$key:0:4}/{$key:0:5}/{$key}.dat
```

SS速報VIPにこの経路を手動追加する必要はありません。現在の組み込み対象は
`ex14.vip2ch.com` の `news4ssnip` 板です。他の板の過去ログ構造まで推測して取得しません。

## 検証

2026-10-17、変数展開・不正な部分指定・URL判定と実サイト取得の34項目を確認し、ビルドに成功しました。
242 devのエミュレータで上記URLを開き、28,468バイトのdatの自動保存と、
「[VIP]高垣楓『違いの分かるひと』」全49レスの件数表示・本文表示をスクリーンショットと取得ログで確認しました。
191／226 devは共通実装の対象ですが、この過去ログの実画面確認はまだ行っていません。
