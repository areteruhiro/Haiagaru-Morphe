# Haiagaru 1.7.8 (Pre-release)

## 1.7.7からの修正

- ChMate 0.8.10.241／0.8.10.242 devで、未読スレを読んでスレ一覧に戻った後も、左下のツールバーに古い未読数が残る問題を修正しました。
- 既読数の変更通知が省略されていた処理を補正し、未読合計を再計算するようにしました。未読数を一律に0へ変更する処理ではありません。

241／242 devの両方で、実機の既読変更通知に未読合計が追従することを確認しました。修正前の242では同じ検証で表示が更新されないことも確認しています。

1.7.7の機能は引き続き含まれます。対象はChMate 0.8.10.191 dev／0.8.10.226 dev／0.8.10.241／0.8.10.242 devです。今回の未読合計修正は241／242 devに適用されます。243 devは一部機能が未対応のため非推奨です。

Android Morphe用パッチバンドルです。正式版の取得先は1.7.1を維持します。
