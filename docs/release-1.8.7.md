# Haiagaru 1.8.7 (Pre-release)

1.8.6からの変更点です。更新前に大切な設定・NG・履歴をバックアップしてください。

## Web検索・設定画面・フィルタの修正

- **191 dev：本文の一部選択 → Web検索**を、外部アプリの別タスクで起動するよう変更しました。検索先ブラウザがHaiagaru側のタスクに残り、戻る操作でブラウザのタブばかり閉じてしまう問題への対策です。検索アプリがない場合のGoogle検索ページも同じ方式で開きます。内部ビューアや通常のリンク表示は変更しません。
- **191／226 dev：設定画面の右端に細い区切り線が出る問題**を修正しました。夜・暗テーマで目立つ、画面外の詳細ページの境界線だけを抑制します。タブレットの2ペイン表示に必要な内側の線は残します。
- **226 dev：「上部のフィルタを削除する」を有効にしても残る問題**を修正しました。リストの再計測でもフィルタ行を高さ0にし、元の行と余白を非表示にします。ツールバーからのフィルタ操作は維持します。

## スレタイの行間

- 191 dev／226 dev／241／242 devで、105%以上にしてもスレタイ上側の余白だけが増え、値を変えても差が出ない問題を修正しました。
- 複数行のタイトルの行間に指定割合を反映し、最終行の下側や1行タイトルには不要な間隔を追加しません。100%では今回追加する行間補正を外します。

## Imgurログインアップロード・投稿一覧（開発中）

パッチ導入時に「Imgurログインアップロード（開発中）」を選択した場合の変更です。

- 投稿一覧を閉じる際、通信キャンセル・接続プール解放をバックグラウンドへ移し、`NetworkOnMainThreadException`でクラッシュする経路を修正しました。
- 動画の処理結果が`completed`でも処理中と判定し続け、URLを取得できない問題を修正しました。不明・未完了の結果を完了扱いにはしません。
- ログイン経由の成功したアップロードを、ChMate標準の画像アップロード履歴へ残せるようにしました。ログイン画面の設定でオン／オフできます（初期オン）。匿名アップロードの既存動作は変更しません。
- アップロード元スレの記録・投稿一覧での表示をオン／オフできます（初期オフ）。有効化後にスレURLが判明するアップロードが対象で、既存の投稿からスレを逆引きする機能ではありません。
- 表示するのは**アップロード元スレ**です。画像URLを掲示板へ実際に投稿できたことまで確認するものではありません。アカウントを区別して端末内に記録し、オフにしても既存の記録は削除しません。
- 非公式Web方式のため、Imgur・Googleの仕様変更や利用制限により利用できなくなる場合があります。結果不明時は投稿一覧を確認してから再送してください。

## 動画専用ビューアを任意のパッチへ変更

- パッチ適用時の「動画専用ビューア」を追加しました。**初期状態は未選択**です。1.8.6で利用していた方も、継続利用する場合はパッチ適用時に選択してください。導入後のHaiagaru設定でのオン／オフも維持します。
- 未選択時は専用Activityを登録せず、過去のオン設定が残っていても専用ビューアへ誘導しません。従来の動画表示・外部アプリ起動を維持します。
- 選択時はChMateのジェスチャー割り当て・全体オン／オフ・判定距離を共有します。「戻る／タブを閉じる」で終了、「先頭／末尾」でシーク、「更新」で再読込、「全画面」で操作パネル切替、「設定／NG編集」で該当画面を開けます。
- スレ削除や書き込みなど動画に対応しない操作は実行しません。ボタン・シークバー操作と画面タップによるパネル切替は維持します。
- パッチの任意化は、MPP配布ファイルそのものの大幅な容量削減を意味しません。既存機能・対応ABIを削除する変更は行っていません。

## 対応・検証範囲

- 対象：ChMate `0.8.10.191 dev`／`0.8.10.226 dev`／`0.8.10.241`／`0.8.10.242 dev`。243 devは引き続き非推奨です。修正対象版は各項目の記載をご確認ください。
- Android向けMPPを配布します。Morpheのプレ版を更新後、元のAPKへパッチを適用し直してください。正式版の取得先は1.7.1のままです。
- 行間は191／242の実際のAndroid TextViewで各366項目、226のフィルタは11項目、設定右端は191／226で各9項目、Web検索は191で8項目のエミュレータ検証を実施しました。Web検索は模擬Contextを使った起動要求の検証で、報告されたSamsung実機でスレへ戻る操作の確認はまだです。
- Imgurは模擬結果を使った履歴・アカウント分離・通信解放の19項目と、標準履歴の保存／再読込・スレ表示の5項目を191で検証しました。動画の処理完了応答とURL取得も検証しています。実サーバーの画像削除・掲示板への投稿は今回行っていません。
- 動画ジェスチャーは4版の認識器を静的検証し、191ではネイティブ経路から起動した画面で「戻る」ジェスチャーを確認しました。226／241／242のジェスチャー手操作、実機の夜／暗テーマ、ユーザー独自フォントを含む全組合せ、長期のセッション維持は未検証です。
- 検証は各機能で実施済みの範囲です。全変更を全版・全端末で実操作確認したものではありません。MEGA・実験的VPN・巨大バックアップなど従来の制約も継続します。
