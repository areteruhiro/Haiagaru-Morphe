# Imgurアルバム内の動画添付（1.8.6プレリリース）

Imgurの `/a/{ID}` から取得する公開メタデータについて、画像に加えて `.mp4` を添付候補にする。
画像と動画の混在・複数件・重複排除に対応する。JSONが取得できない場合のHTMLメタデータも
`og:video` / `og:video:url` / `og:video:secure_url`を優先し、動画がないときだけ画像へフォールバックする。

- 対象: 191 dev / 226 dev / 241 / 242 devの既存共通添付処理。
- ログインCookieは不要。取得先は検証済みのHTTPS `i.imgur.com/{ID}.mp4`。
- URLメディアの既存取得設定に従う。画像取得オフ・動画のみの場合もアルバムを解析する。
- 動画は既存の動画モデルへ渡す。サムネイル生成は既存の容量・時間上限を適用する。
- 本文のURL文字列は書き換えない。本文からの自動再生は追加しない。

## 検証

- `https://imgur.com/a/IZl4GMB` の公開JSONにMP4が1件あることを確認。
  対応する動画URLへのHEADはHTTP 200、Content-Typeはvideo/mp4。
- `VerifyImgurAlbum`: 画像・動画混在、重複、異常ID、失敗応答、動画HTML優先、偽装ホスト拒否を検証。
- `VerifyXMedia`: Imgur動画のネイティブ動画判定、既存XのURL抽出を検証。
- この取得処理の追加後、動画専用ビューアの検証で191の実再生を確認した。
  226／241／242は生成APKの静的検証を中心とし、全版の実再生を確認したものではない。
