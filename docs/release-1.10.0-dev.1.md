# Haiagaru 1.10.0-dev.1（プレリリース）

正式版1.9.3からの開発版です。設定・投稿検索の画面変更を含みます。

## 画面と操作

- Haiagaru設定とワッチョイ／エッヂ検索をJetpack Compose＋Material 3 Expressiveへ変更しました。設定は8カテゴリに整理しています。
- 設定検索の結果から直接オン／オフを変更でき、自動保存後のチェック状態を反映します。切替時も検索語と結果の位置を保持します。
- ツールバーの表示・非表示はChMate標準のツールバー設定で変更します。Haiagaru本体設定の重複スイッチを整理しました。
- 投稿検索のオン／オフ、検索先の表示、通知、履歴・キャッシュの保持設定は、投稿検索画面に集約しました。

詳しい操作は[Compose版の設定・投稿検索画面](compose-settings.md)を参照してください。

## 修正

- 5chの「ﾜｯﾁｮｲで検索」でHissiを選ぶと「この板では選択した検索先を利用できません」となる問題を修正しました。元の板とワッチョイ全体を引き継いでHissiの検索画面を開きます。対象日を確認して「選んだ板を検索」で開始してください。
- BEログインボタンのメニューへ「Imgur投稿一覧」「アップロード先を変更」等が混入する問題を修正しました。通常の書き込みメニューにだけ追加します。

## 引き継ぎと確認範囲

設定キー、保存先、履歴、バックアップは引き継ぎます。アプリのデータ消去は不要です。動画ビューア・MEGA・Imgurログイン等の任意パッチ選択は維持します。

ローカルでAndroid用MPPビルドが成功しています。Compose移行時の191／226／242へのAPKパッチ適用は成功していますが、その後の設定検索・Hissi・BEメニュー修正を含む版のAPK適用と実画面操作は未確認です。端末へのインストール・実機／エミュレータでの確認は今回行っていません。

プレリリースとして公開します。実装・ビルド成功と端末動作確認は区別してください。
