# Haiagaru 1.8.5 (Pre-release)

1.8.4からの変更点です。更新前に設定・NG・履歴をバックアップしてください。

## 「書き込んだスレ」の表示数を修正

- 191 dev／226 dev／241／242 devで、Haiagaru設定の表示数を実際の一覧へ反映するようにしました。242で20件を指定しても10件のままになる問題を含みます。
- 1〜10000件を指定でき、0は無制限です。件数を変更してOKを押すと、アプリを再起動して一覧を作り直します。
- この設定は「書き込んだスレ」欄だけを制限します。「下書き」「送信済み」の件数や、保存済みの履歴は削除しません。

## 書き込み履歴の保存数・無制限保存

- 241／242で「書き込み履歴に残す件数」が内部の100件固定処理へ反映されない問題を修正しました。
- 191／226も含め、件数変更時は再起動して反映するようにしました。保存数の制限は、次に履歴を保存するときに適用されます。
- 新しく「書き込み履歴を無制限に保存」スイッチを追加しました。ONでは件数による削除を行いません。OFFでは1〜10000件を指定でき、従来どおり0は「残さない」です。
- 無制限保存では、保存容量・バックアップサイズ・起動や一覧表示の負荷が増える場合があります。すでに削除された履歴を復元する機能ではありません。

「書き込んだスレ」の**表示数**と、「書き込み履歴」の**保存数**は別設定です。

## 閲覧履歴・検索履歴の件数設定

- 「閲覧スレ履歴を無制限に保存（自動削除しない）」を追加しました。ONでは古いスレ履歴・DATの件数による自動削除を止めます。手動削除は可能です。
- OFFでは閲覧スレ履歴の保存数を1〜10000件で指定できます。ChMate標準の自動整理のタイミングで適用され、指定件数を常に厳密に維持するものではありません。
- 「最近見たスレの表示数」は1〜10000件、0で無制限にできます。保存数とは別に設定できます。
- 「検索履歴の保存数」は1〜10000件、0で無制限にできます。次の検索履歴保存から反映します。ChMateの「検索履歴を保存」がOFFの場合は保存しません。
- 板の履歴には今回新たな件数制限を加えていません。
- 変更時はアプリを再起動します。無制限保存は容量や読み込み負荷が増える場合があり、削除済み履歴の復元はできません。

## 対応と検証

- 対象：ChMate `0.8.10.191 dev`／`0.8.10.226 dev`／`0.8.10.241`／`0.8.10.242 dev`。
- 4バージョンへのAndroid MPP適用と、生成DEXの件数フックを確認しました。
- API 36エミュレータの検証専用アプリで、仮の25スレ・25件の履歴を使い、表示数1／3／10／20／10000／無制限と、保存数0／3／20／100／無制限を検証しました。実際の掲示板への投稿はしていません。
- 241では、設定ダイアログの無制限ON／OFFと20件への保存、再起動要求も確認しました。
- 4バージョンで、検索履歴の標準の保存・読み出し処理を呼び、20件／1件／無制限（仮の65件）、重複語の先頭への移動、保存OFFを確認しました。
- 閲覧スレ履歴の無制限ONでは自動整理のDB照会に進まず、OFFでは標準処理へ進むことを確認しました。検証中の標準処理はDB照会で止め、実際の履歴削除は行っていません。
- 最近見たスレは生成DEXの適用箇所と件数補正を確認し、242では実際のSQLクエリ生成時の件数も検証しました。全画面を手操作した確認や、大量DATを使った自動整理の長期検証は未実施です。
- 数万件以上の履歴を使った性能検証、全実機・OSでの動作確認、Morphe実機画面でのバンドル更新確認は未実施です。
- Morpheのプレリリースを有効にし、バンドル更新後、元APKにパッチを適用し直してください。正式版の取得先は変更しません。
