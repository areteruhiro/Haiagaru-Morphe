# 直接動画URLのサムネイル（1.9.0）

Imgur／Xに限定せず、HTTP(S)の直接動画ファイルURLからフレームを抽出する。対象拡張子はMP4／M4V／WebM／MOV／3GP／3GPP。実際に解析できる形式は端末コーデック次第。Webページ・m3u8等の配信リスト・ログインや保護解除が必要な動画は対象外。

画像・動画の既存自動取得設定に従い、容量・時間上限、分割プレビューのWi-Fi条件、非公開別プロセスでの解析を維持する。「動画フレームからのサムネイル生成」で新規生成を停止可能。

元レスの本文から直接URLを再抽出するため、画像のみモードで動画URLが添付キャッシュから除去された後も、生成済みサムネイルを再結合できる。Imgur直接MP4がX限定の再抽出から漏れていた経路も補正。

生成画像は端末内のループバック配信経由で標準表示へ渡す。入力としてlocalhost等のループバックURLは対象外。失敗時にアプリ本体が落ちないよう解析を別プロセスに分離。サイト別の規約・アクセス制限を回避するものではない。

検証: Imgur抽出13ケース、一般直接動画ポリシー21ケース成功。実機で別プロセス起動・JPEG生成は確認済みだが、この一般化版の各サイト・各形式の表示成功は未確認。

1.9.0の収録内容です。最終候補のビルド・版別適用・実機確認の結果は[1.9.0の案内](release-1.9.0.md)を参照してください。本文中の検証記録はその実施時点の結果です。
