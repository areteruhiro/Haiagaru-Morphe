# Haiagaru 1.9.0 — プレ版1.8.15からの変更

1.8.15と現在のパッチソースを比較し、未公開の1.8.16候補と、その後の追加・修正を正式版1.9.0へまとめました。1.8.16は公開取り下げ状態で、今回の比較元には使っていません。正式版1.7.1をご利用の方は[累積の変更案内](release-1.9.0-from-1.7.1.md)をご覧ください。

## 対応版・更新方法

対応は **ChMate 0.8.10.191 dev／226 dev／242 dev**。241／243 devは対象外です。元のChMate APKへ再度パッチを適用し、事前にバックアップしてください。同じパッケージ名・署名で更新すると保存データを引き継げます。

「Change ChMate package name」のversionCode初期値は **2,100,000,000** です。対応版間の切り替え時に低いコードで上書きが拒否される問題を避けるための設定です。適用前に変更／解除できます。最大化後は低いコードのAPKへ通常の上書きはできません。非対応版の互換化や署名違いを解消する機能ではありません。

## 検索：四文字の必須解除・エッヂのID／レス本文

- ワッチョイの四文字固定・必須条件を解除。Hissiは上側／下側の部分一致で検索し、空欄なら選択した板・期間内の投稿者を広く走査します。
- 板を複数チェック・折りたたみ、日付をカレンダーで指定し、続きから再開できます。取得した投稿者ページのスレ名・本文を表示します。
- **エッヂはKyodemo経由**で現行／過去ログを選択し、投稿ID・スレ名・各レス本文を照合します。`/GNQXmAUz`／`ID:/GNQXmAUz` を入力できます。ID欄を空にして本文だけでも検索でき、キーワードは空白区切りAND条件です。スレ名・本文は大文字小文字を区別しません。投稿IDは大小を区別する部分一致です。
- スレ名を入力した場合、`?bs=&kt=k_&fr=&to=&k=検索語` のKyodemo板検索から取得します。検索語付きのページ送りと、50レスごとの続きページに対応。現行スレ指定時は`kt`が空です。エッヂ開始ではZZZSearchへ切り替えません。
- Kyodemoの一覧に残っていても本文が404のスレは「未収録」と数え、次のスレへ進みます。掲載されていない投稿は取得できません。
- 走査上限は **初期100・最大10,000**。Hissiは一覧ページ数、エッヂはスレ件数です。0＝無制限は使いません。一覧を1ページずつ読み、順に走査します。
- **通信回数上限**を別に指定できます。初期0は無制限。開始／「続きから検索」ごとに取得試行を数え、404等の応答も含みます。キャッシュからの再利用は数えません。上限に達すると停止し、続きから再開できます。回数はページ取得単位で、通信量（バイト数）の制限ではありません。
- 通知付きバックグラウンド検索を追加（初期オフ）。通知から戻る／停止できます。プロセス終了・強制停止後の自動再開は行いません。
- ZZZSearchはアプリ内Web表示に対応し、スレ名だけ・書き込み内容だけ・条件の組み合わせで検索できます。検索サービスの全文インデックスなので本文のみの厳密照合とは異なります。
- 表示設定の「ZZZSearch関連を表示」「エッヂ関連を表示」を個別にオフにできます。検索画面を開き直すと反映します。

[検索操作・制限](zzzsearch-internal.md) ／ [バックグラウンド・履歴の操作](wacchoi-background-search.md)

## 検索履歴・保持設定・バックアップ

- 検索条件と結果を保存し、通信なしで表示／同じ条件で再検索を選択。履歴・保存結果をID・スレ名・本文等で検索できます。
- チェックした履歴の選択削除と全履歴削除を追加。確認後に削除し、ページキャッシュは残します。実行中セッションの遅延保存で履歴が復活する経路も補正。
- 件数・合計容量・1件の容量／件数／文字数、ページキャッシュ容量・再利用時間を指定できます。ここでの **0は無制限／無期限**。初期値は履歴20件・合計32MiB・1件2MiB、キャッシュ16MiB・24時間です。走査上限とは別の設定です。
- MEGA／ローカルZIPの対象に検索履歴・保存結果と取得ページキャッシュを個別追加（初期オフ）。旧版は新カテゴリ入りZIPを復元できません。省略・削除済みの結果は保持量を増やしても戻りません。ZZZSearchのWeb結果は履歴保存対象外です。

## 設定・表示・ジェスチャー

- 一般 →「追加機能のオン／オフ一覧」に34項目を集約。専用カテゴリと同じ設定値を使います。保存データは削除しません。一部の数値設定は標準値へ戻す方式で、すべての機能を一括停止するスイッチではありません。
- レス長押し・ツールバー追加項目を個別設定。未設定の「過去レスを見る」「上／下4桁検索」「ﾜｯﾁｮｲで検索」「投稿者を強調」「レスを保存」は初期非表示です。保存済み設定・順序を引き継ぎ、明示的な個別表示を優先します。
- 表示スイッチと標準ツールバーの保存済み非表示設定の優先順位を修正。再起動が必要な変更は「今すぐ再起動／あとで」を案内します。
- Haiagaru設定内でChMateのジェスチャーを利用し、戻る・閉じる・先頭・末尾に対応。
- 上側・下側の検索アイコンを矢印へ変更。全体のワッチョイ検索は虫眼鏡。★スレの説明は「★スレのみ巡回」へ変更。
- エッヂ記者IDを「長押し/NG Threads時に追加」「板のスレ一覧に追加」で独立設定。旧値は初回に両方へ引き継ぎます。
- HOMEの未読・履歴・スレでDAT落ちスレを非表示にする任意設定を追加（初期オフ）。DBやログを消さず、オフにすると再表示します。
- 242 devでスレ順キーワードが出ない経路と、HOME更新時にキーワード並びが切り替わる経路を補正。

## 人気レス・X・動画

- 直接返信数で人気レスを判定し別ポップアップへ表示（初期オフ、閾値初期3）。同じレスの重複アンカーは1件、返信の連鎖は加算しません。暗色背景の文字色と元レスへの移動も調整。
- Xプレビューの解析・本文再設定・表示行更新を軽量化。任意のカード表示と返信／リポスト／いいね／リンクコピー欄を追加。反応操作はX側のページで行います。
- 内部動画ビューアで0.5〜2倍の速度切替、画面長押し中だけ2倍速。YouTube等では同一操作に対応しない場合があります。
- HTTP(S)の直接動画ファイルURLからフレームサムネイルを抽出。対象拡張子はMP4／M4V／WebM／MOV／3GP／3GPP。実際の対応は端末のコーデックに依存し、配信リストや保護動画は対象外です。
- サムネイルのネイティブ解析を非公開の別プロセスへ分離し、異常終了・タイムアウト時は新規解析を停止。端末依存のネイティブクラッシュすべてが解決したとは扱いません。

## 保存・その他の修正

- スレッドアーカイブをスレ作成日時／保存ファイル更新日時の昇順・降順で表示。
- エッヂの次スレ検索へ、タイトル変更後の関連候補を追加。
- 全期間の閲覧履歴整理で時刻不明の古い履歴も対象に。
- 既読スレ削除ジェスチャーの画面検出、投稿者強調時の不要な再レイアウト、書き込みメニューの追加項目表示を補正。
- 改行までゼロ埋めされた復元DAT行を補完し、特定条件の「未読1」へ対処。未読不整合全般の修正ではありません。
- Talkのレスポップアップを広告余白削除から除外し、初回取得時の画面復帰Intentを補正。タップや「進む」に関する残存報告は引き続き確認対象です。

## 確認範囲・注意事項

ビルド・判定ロジック・実ページ解析・APKへのパッチ適用と、実機の全機能確認を区別しています。1.9.0最終候補で191／226／242元APKへの適用が成功し、226／242では動画・MEGA・Imgurログインの任意パッチ込みでも適用を確認しました。XIG05上の191 devへ同一署名で上書き・起動を確認しました。Kyodemoの検索URL・続き50レスの解析、404未収録の再現、通信上限の境界・再開カウントは個別確認しています。人気レス7件・関連スレ15件・直接動画URL21件・HOMEキーワード保持19件の判定確認も成功しました。

10,000スレの全件走査、検索画面からのすべての操作、226／242の新機能の全実画面、追加検索データのバックアップ完全復元、全サイト・形式の動画、人気レスの位置・既読状態、Talk復帰などの通し確認は未完了です。Morpheの端末画面での更新表示も未確認です。

任意パッチ（動画・MEGA・Imgurログイン・実験的画像VPN等）の選択は維持しています。MEGAはAndroid 7.0以降が必要です。外部サイトの収録・仕様変更・認証・OS制御により動作範囲が変わります。
