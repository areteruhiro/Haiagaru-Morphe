# 復元したログで未読が1件残る場合の補正

DATの行全体がゼロ埋めされ、改行まで失われている場合、取得済みレス数が1件少なくなり、一覧の未読が消えないことがあります。復元操作自体がゼロ埋めを発生させたかどうかは未確定です。

標準DATパーサーで読み込む前に、行頭から始まる十分な長さのゼロ領域に、削除済みレスの代替行を入れます。本文は復活させず、バイト数を維持して後続レスの番号を保ちます。既読数やサーバーのレス数を強制変更する処理ではありません。先頭行・短い領域・ファイル末尾の未完領域は変更しません。

変更前のDATは、ChMateの外部保存フォルダ内 `haiagaru-dat-recovery` に `.original` として保持します。自動削除しません。アプリ削除時には失われる場合があります。

## 確認

- 正常ログなどを維持するホストテスト6件。
- エミュレータ191の標準パーサーで、実機由来の104302バイトのログが360→361レスとなり、ファイル長は不変。
- 実機191で同じ処理をFridaから適用。ChMateの通常閲覧後、DBの `res_count / server_res_count / read_count` が `361 / 361 / 361` で一致。
- Android MPPビルドと191へのパッチ適用が成功。実機APKとは署名が異なるため、APKの上書きは行っていません。
