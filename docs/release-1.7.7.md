# Haiagaru 1.7.7 (Pre-release)

対象：ChMate 0.8.10.191 dev / 0.8.10.226 dev / 0.8.10.241 / 0.8.10.242 dev。
243 devは一部機能が未対応のため非推奨です。

## 追加・改善

- スレ一覧のタイトル行間を、標準に対する100〜200%（5%刻み）で変更できます。カスタムフォントで下端が欠ける場合は割合を上げてください。100%は元の表示を維持します。変更保存後にアプリを再起動します。
- Instagramの公開投稿・リールから画像／動画を取得し、レスの添付メディアとして表示します。複数画像の投稿にも対応します。本文の投稿URLは変更しません。
- 名前／ワッチョイの長押しメニューに「ﾜｯﾁｮｲ下4桁でNGName登録」を追加しました。ワッチョイ前半が違っても、末尾4文字が同じ名前をまとめてNGにできます。確認後、ChMateのNGネームへ正規表現として登録します。全板が対象で、解除・編集は通常のNGネーム設定から行えます。大文字・小文字と記号を区別します。別の利用者が同じ末尾になる場合があるのでご注意ください。
- Imgurアルバムから複数枚の画像を取得します。
- Xの公開投稿から画像／動画を取得します。`video.twimg.com`の直接動画URLにも対応します。
- 「URLメディア：画像の場合」「URLメディア：動画の場合」を別々に設定できます。動画は「画像のみ（サムネイル）／画像＋動画／動画のみ／取得しない」から選べます。「動画のみ」でも動画枠のサムネイルを表示します。
- 動画サムネイル用の一時ダウンロード上限を1〜1024 MB、制限時間を1〜600秒で設定できます。初期値は24 MB・20秒です。
- 191／226の画像ビューアに背景なしの「⟳」回転ボタンを追加しました。画像カウンターと連動して表示・非表示になります。
- エッヂ `d1ch.cc/edge` の必死チェッカーメニュー／Kyodemoルーティングを補正しました。保存済みのメニューテンプレートも更新します。

## 使い方と制限

行間とメディア取得は「ChMate設定 → Haiagaru」で変更できます。

Instagram／Xは公開ページで取得できる範囲が対象です。ログイン必須・非公開・削除済み投稿、地域制限、サイト側の仕様変更／取得制限には対応できない場合があります。ログイン情報を送信したり、アクセス制限を回避したりする実装ではありません。

動画サムネイルは通信量を消費します。大きな動画や取得に時間がかかる動画は設定した上限に達すると取得を中止します。動画そのものの再生は端末の動画プレイヤーに依存します。

本リリースはAndroid Morphe用MPPの検証版です。正式版の取得先は1.7.1のまま維持します。
