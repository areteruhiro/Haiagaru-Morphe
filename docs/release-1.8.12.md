# Haiagaru 1.8.12 (Pre-release)

1.8.11からの変更です。対応はChMate 191 dev／226 dev／242 devです。

## 修正・改善

- X投稿プレビューの更新が繰り返し呼び出され、アプリが落ちる問題を修正しました。
- 動画の操作パネルが表示されている間も、スワイプジェスチャーを使えるよう補正しました。
- アーカイブ一覧の「レスのアーカイブを開く」がステータスバーに重なる問題を修正しました。
- 保存レスの詳細に「ヘッダー＋本文をコピー」を追加。レス番号・名前・メール欄・投稿日時・IDなどと本文をまとめてコピーできます。
- レスアーカイブの「並び順」から、保存日時／投稿日時それぞれの昇順・降順を選べます。並び順は記憶され、投稿日時が不明なレスは末尾に表示します。
- コマンド候補を板別・用途別に拡充しました。5chのID・SLIP・どんぐり関連、名前欄用コマンド、おーぷん2chの自演防止・アク禁／解除を追加。エッヂの表示コマンドも利用できます。候補は編集して板ごとに保存できます。
- 5chの「板設定を取得」で `SETTING.TXT` を確認できます。読み取り専用で、下書きの変更・自動投稿は行いません。

操作方法は[スレ立てコマンド](thread-commands.md)、[レスアーカイブ](response-archive.md)、[動画ビューア](video-viewer.md)をご覧ください。したらば／AfternoonTeaは自由入力と仕様案内で、未確認のコマンドは登録していません。

## 検証・注意

Androidパッチのビルド成功を確認。Xプレビューの再入防止はAndroid上50チェック、動画コントロールのフォーカスは7チェック、アーカイブのコピー・余白と並び順はそれぞれ14チェックを確認しています。コマンドは判定など82ケースと191のAndroidダイアログ8チェック、191／226／242の本文・名前欄への接続検査に合格。実スレ立て・返信送信、および226／242の新コマンド画面の操作は未確認です。すべての板・端末での動作を保証するものではありません。

更新前に重要なデータをバックアップしてください。正式版1.7.1の取得先は変更しません。既読スレ一括削除ジェスチャーは今回に含めず、別途対応予定です。
