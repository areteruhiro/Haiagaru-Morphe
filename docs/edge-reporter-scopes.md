# エッヂ記者IDの表示先

Haiagaru設定 → 画面・文字の表示（および追加機能のオン／オフ一覧）に次の2項目を用意。

- **エッヂ記者ID：長押し/NG Threads時に追加**：従来の `edgeReporterId` を引き継ぐ。長押しメニュー・NG追加と履歴側のタイトル補完を制御。
- **エッヂ記者ID：板のスレ一覧に追加**：板を開いたスレ一覧の記者ID表示を独立して制御。ここでの「板一覧」は掲示板名の一覧ではなく、エッヂ板内のスレ一覧を指す。

最初の起動時に旧スイッチの値を板一覧用スイッチへコピーする。以降は独立し、既に変更した設定を移行処理で上書きしない。

片方でもオンなら記者ID付きsubjectを取得する。板一覧では表示境界でキャッシュのIDを補完し、オフの場合は取得済みタイトルのIDも表示時に除去する。取得済みメタデータを消さず、元のNG判定・スレ順を変更しない。両方オフなら通常のsubject取得に戻る。

一覧を開き直して反映。取得したことのないIDは板の更新が必要。

検証: ビルド成功。`scripts/VerifyEdgeReporterScopes.java` の65ケースで、4通りのオン／オフ・旧設定移行・191／226／242の表示モデル・他板への非干渉・表示状態の解放を確認。合成データによる独立プロセス検証で、実際の板一覧／NG画面の通し確認と今回版のインストールは未実施。
