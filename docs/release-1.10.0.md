# Haiagaru 1.10.0（正式版）

安定版1.9.3とプレリリース1.10.0-dev.1〜dev.3からの更新です。対応するChMateは191 dev／226 dev／242 devです。

## スレを開いた直後のクラッシュ

dev.3の191でスレを開くと `VerifyError` で終了する問題を修正。タブ復帰時の再読込抑制処理が本体のレジスタを上書きしていました。191／226／242で別メソッドへ判定を移し、初回読込を維持しました。設定をオフにするだけでは検証エラーを回避できないため、元APKへ修正版パッチを再適用してください。[更新方法と設定](tablet-resume-reload.md)

## 表示と操作

- YahooニュースなどのWebサイトを、Open Graph等の共通メタ情報でカード表示する機能を追加。「スレを読む → リンクカード・Xのプレビュー → Webサイトのリンクカードを表示」で有効化。初期値はオフ。[詳細](site-link-cards.md)
- GIF専用ビューアを動画専用ビューアの任意パッチへ追加。[操作](video-viewer.md)
- NG管理、履歴、外部板、アップロード、メディア操作などの独自画面・ダイアログをCompose／Material 3へ移行。複数DEXの同梱とライブラリ隔離に対応。[移行範囲](compose-ui-migration.md)
- レスフィルターにAA・自分・返信と件数表示を追加。[使い方](response-quick-filters.md)
- 画面幅によるスマホ／タブレット表示の自動切替を追加。初期値はオフ。[詳細](fold-layout.md)
- Imgur投稿一覧の表示切替とCompose画面を追加。★スレの追加項目は初期未選択に変更。

## 修正

- 長押しワッチョイ検索の表示設定、全文検索のKyodemo／Hissi切替、投稿検索の設定トグル即時反映を改善。
- ZZZSearchを閉じた後も検索画面の更新通知を維持。動画サムネイルの生成設定を再配置し、旧版で無効にした設定を戻せるよう修正。文字サイズなどの小数入力キーボードを引き継ぐ。
- DAT落ちスレの一覧非表示を再公開時にも適用。下書き・送信済みを独立設定で非表示にできるよう追加。初期値はオフで、本文や履歴は削除しない。[詳細](hide-dropped-home-threads.md)
- 投稿者IDを対象にした標準NGの連鎖を補修。NGWordに一致した投稿者の別レスへの返信と、その先の返信も連鎖NGにします。同じNGWordで「連鎖」「投稿者のIDもNG」を両方オンにしてください。[登録手順・判定サンプル](ngword-poster-chain-example.md) ／ [仕様](poster-id-chain-ng.md)
- 手動サムネイルのURL解析をキャッシュし、同じ添付URLでの不要なキャッシュ破棄と更新通知を削減。報告された枠の消失・カクつきの改善を実機で確認したものではない。[確認範囲](manual-thumbnail-performance.md)
- 191／226／242のタブ復帰時の自動再読込を抑制する設定を追加。初期値はオン。「アプリ・通信」の通信設定から切り替えます。更新ボタン、初回読込、アプリ自体の復帰はChMateに従います。[操作](tablet-resume-reload.md)
- バックアップのローカル／MEGA入口・保存対象の分離、★情報の復元、保存後の読み直し照合、進行・結果通知を改善。[詳細](mega-backup.md)

## パッチ容量と導入

絵文字フォント・191画像判定修正・実験用VPNの資材をMPPから分離し、必要なファイルだけ選んでAPKへ組み込む方式に変更。画像判定ZIPはリリースにも添付する。[初めての方の導入手順・直接ダウンロード・ライセンス](optional-assets.md)

## 確認範囲

対応対象は191 dev／226 dev／242 dev。修正前の191 APKをAPI36エミュレータへ導入し、スレ画面Fragmentの生成時に実機と同じVerifyErrorが出ることを再現。修正後は3版へ同じ固定MPPを適用し、元APKとの比較で呼び出し元のレジスタ・引数・分岐と初回読込の維持を確認しています。版ごとのエミュレータ検証結果は[統合記録](integration-status.md)に記載します。

3版のエミュレータ実プロセスで各9項目、計27項目に合格。ネイティブFragmentの生成、修正版メソッドの存在、初回復帰・同一タブへの再復帰・Activity自体の復帰・オフ時・スマホActivityの判定を確認しました。復帰条件の検証には検証用Activity／Fragmentを使用しており、実際のタブを切り替えて通信回数を計測した確認とは異なります。検証中の対象パッケージに新しいクラッシュ記録はありません。

dev.3公開前には旧191フル版のXIG05への別パッケージ導入とホーム起動、サイトカード、GIF、VPN、絵文字、画像判定修正の同梱を確認しましたが、その後スレ表示時のクラッシュが判明しました。今回の修正版の実機再導入は未実施です。下書き／送信済みフィルター14項目、投稿者ID連鎖130件等の過去の個別検証は統合記録を参照してください。

サイトカードの実画面、全ダイアログ、折り畳み実機の開閉、実サーバーに対するタブ再読込の通信回数、VPNの全経路は未確認です。指定された公開スレのHTMLは取得できましたが、ADBからそのURLを直接開く操作は実行環境の自動承認で拒否されたため、同URLの本文を表示しての通し操作は確認に含めません。

ローカルの最適化ビルドではAndroid LintのKotlin FIR内部例外のためLint工程を除外した。通常リリースは公式テンプレート由来のSemantic Release CIで生成する。最終的なCI結果と公開物はGitHub Actions／Releaseを参照。
