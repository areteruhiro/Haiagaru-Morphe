# Imgur Webアカウント送信（開発中）

## セッション維持の補正（未公開）

- API応答のSet-Cookieをアプリ内WebViewのCookieManagerへ反映して保存する。
  有効期限・Domain・Path等はサーバーの指定を維持し、削除指示もそのまま反映する。
  HTTPSのapi.imgur.com限定で扱い、他サイトのCookieを保存・移送しない。
- アカウント確認後・処理待ちの次の通信では最新のCookieを読み直す。
  古いCookieへのフォールバックや失敗した投稿の自動再送はしない。
- ログイン画面のonPause/onDestroyでもCookieを保存する。
- HTTP 403はアクセス拒否として表示し、無条件にログアウトと判定しない。
- Cookie応答反映テスト、既存URLポリシー77件、Androidバンドルビルドが成功。
  定期ログアウトの直接原因の確定・長期間経過後の維持確認は未実施。
  Imgur側の失効・期限切れや追加認証を回避するものではない。

パッチ適用時に「Imgurログインアップロード（開発中）」を選択してください。
初期状態は未選択です。通常のHaiagaruのみではログイン設定を表示せず、
Webアカウント送信は動作しません。以前有効化した設定が残っていても、
このオプションを外して適用し直すと無効になります。

対象: ChMate 0.8.10.191 dev / 226 dev / 241 / 242 dev。

Haiagaru設定の「Imgurにログイン／Webアカウント送信」から、アプリ内の
Imgurログイン画面を開きます。ログイン後に「確認・有効化」を押します。
有効化後は既存の画像選択・サイズ変換・アップロード・本文へのURL挿入を利用します。
初期状態は無効で、元の匿名アップロード処理を変えません。

Chrome等の外部ブラウザのCookieは読み取りません。このアプリのWebView内で
作成されたセッションだけを使用し、パスワードの取得やJavaScript bridgeは実装しません。
Googleログインの遷移先（accounts.google.com）と操作によるログイン用ポップアップも
アプリ内WebViewで表示します。その他の外部SNSへの遷移は未対応です。
Googleは埋め込みブラウザを拒否する場合があり、認証の成功を保証しません。
WebViewのUser-Agentを偽装したり、認証制限・追加認証を回避したりしません。
拒否された場合はImgur自身のログインを利用してください。
CookieはWebViewがアプリ領域に保存し、ログ・独自TXT・設定エクスポートには書き出しません。
アプリデータ全体を抽出するバックアップにはWebViewのデータが含まれる可能性があります。

Web版の公開JS設定から現在のデスクトップ用公開client IDを取得し、Web版と同じ
Cookie付きアップロードエンドポイントを使用します。OAuth client secretや他アプリの
認証情報は使用しません。これは公式OAuth連携ではなく、Web版の仕様変更で停止し得ます。
無料利用・商用利用の許諾や料金回避を保証するものではありません。

送信前にアカウントを確認し、送信結果の所有アカウントと直リンクを検証します。
有効時は失敗しても匿名送信にフォールバックしません。Cookie付きリクエストの
リダイレクトを禁止し、Cookieはapi.imgur.com以外へ転送しません。
送信を自動リトライしないため、タイムアウト・所有者確認失敗・動画処理中の場合は
再送前にImgur側の投稿一覧を確認してください。すでにアップロード済みの場合があります。
画像・動画の選択や変換上限はChMate標準の処理に従い、本機能では拡張しません。
Web送信のファイル判定は画像およびMP4に対応します。

## 処理待ち時間・投稿一覧（次回更新向け）

- Imgurログイン画面の「処理待ち時間」で、送信後のサーバー処理待ちを0〜1800秒で指定できます。初期値120秒。次回送信から反映し、転送自体のタイムアウトは別です。
- 0秒では変換完了を待たず、処理中の場合は投稿一覧で確認する案内を表示します。すでに完了した画像・動画は0秒でもそのまま扱います。
- 待機中は同じ画像IDの状態をGETで照会し、再アップロードしません。`processing: false`を処理中と誤判定する問題も修正しました。
- 待機終了・通信失敗でもImgur側で処理が続く場合があります。再送前に一覧で確認してください。
- Haiagaru設定・書き込み画面の「Imgur投稿一覧」、ログイン画面の「投稿一覧」から、ログインとは独立したネイティブ画面を開けます。画像・動画と、非公開アップロードを含みます。
- 一覧に画像・動画の静止サムネイルを表示します。「URLをコピー」で直リンクをコピーし、書き込み画面へ戻って貼り付けられます。処理中・取得失敗のサムネイルは代替表示になり、一覧の選択操作を妨げません。
- 「前へ」「次へ」でページを切り替え、「更新」で処理状況を再取得します。処理中や有効な直リンクがない投稿のコピーは無効にしています。
- 書き込み画面では「書き込む」の左側の「︙」メニュー内に「Imgur投稿一覧」を表示します。画面上部に専用ボタンは追加しません。開発中パッチを導入した191／226／241／242が対象で、パッチを外した場合は表示しません。入力中の本文を送信・変更する機能ではありません。
- この変更はローカル開発中です。既存の1.8.5公開バンドルは差し替えていません。
