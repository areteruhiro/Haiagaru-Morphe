# ワッチョイ上・下4桁検索

開発中のCompose版では、検索画面右上の「検索の設定」で変更します。Haiagaru本体設定には重複して置きません。公開済み1.9.3とは画面が異なります。

- 「通知を表示してバックグラウンドでも検索する」は初期オフ。オンにして検索開始すると、画面を閉じても通知付きサービスで検索を継続します。Hissi・Kyodemoのエッヂ過去ログの両方に対応します。
- 通知から検索画面へ戻る・停止ができます。検索画面を開き直すと同一アプリプロセス内の結果と進捗を再表示します。完了・停止後、続きがある場合は「続きから検索」も利用できます。
- 絞り込み文字は任意です。Hissiは選択範囲内のワッチョイ、エッヂは `ID:` を照合し、空欄なら該当範囲を広く走査します。10秒以上の取得間隔、指定ページ／スレ上限、拒否・サーバーエラー時の停止を維持します。表示結果は最大2000件です。取得対象の追加やサイトの制限回避は行いません。
- OSの省電力制御で遅れることがあります。強制停止・プロセス終了・再起動をまたぐ結果保存や自動再開は行いません。
- Android 13以降は通知の許可を求めます。拒否している場合、通知欄での進捗・完了案内は表示されない場合があります。

上4桁・下4桁検索はChMateのツールバー設定から配置できます。表示・非表示と配置はChMate標準の各ツールバー設定だけで変更します。

ワッチョイ長押しメニューにも「ﾜｯﾁｮｲ上4桁で検索」を追加しました。上・下4桁それぞれの表示は、ChMate標準のレスツールバー設定に従います。標準のレスツールバー設定での表示・順序指定も維持します。選択したワッチョイの4文字を検索画面へ引き継ぎます。

## 「ﾜｯﾁｮｲで検索」からHissiを使う

5chのレスで「ﾜｯﾁｮｲで検索」を開き、「hissi.orgで開く」を選ぶと、Hissiの日別投稿者一覧を調べる検索画面へ進みます。元の板とワッチョイ全体（上側・下側の両方）を引き継ぎます。以前使ったエッヂ／ZZZSearchの選択に左右されません。対象日を確認して「選んだ板を検索」を押してください。画面を開くだけでは走査を開始しません。

IDチェッカーの検索先がHissiに固定されている場合、または両方表示で前回Hissiを選んだ場合も、この検索画面を開きます。Hissiに収録されていない板・日付・ワッチョイは検索結果に含まれません。Kyodemo側からHissiへの切替を、未対応板のエラーとして扱っていた処理を修正しました。

## 検索履歴・キャッシュ

履歴一覧の検索欄で4桁・板・ID・スレ名・保存本文を絞り込めます。履歴選択後の「保存した結果の中を検索」は、その回の結果を絞り込みます。空白区切りAND、大文字小文字を区別しない文字列検索です。サイトへの追加通信はなく、保存時に省略した結果やZZZSearchのWeb結果は検索できません。

検索画面右上の「履歴」から、検索条件・結果を開けます（保持件数の初期値20件）。「保存した結果を表示」は追加通信しません。「同じ条件で再検索」は条件を復元して検索し直します。保存結果の表示と自動再開は別で、プロセス終了後も履歴・結果は残りますが、実行中だった検索は自動再開しません。

履歴保存は初期オン。検索画面右上の「検索の設定」からオフにでき、履歴・保存結果とページキャッシュを別々に削除できます。履歴をオフにしても既存履歴は自動削除しません。履歴は全体32MiB・1件2MiB以下で、上限を超える古い履歴から整理します。結果数・本文量が大きい場合は一部だけを保存し、表示時に案内します。

取得ページはアプリのファイル領域へ保持し、24時間以内なら再検索時に再利用します。16MiBを超えると古いページから整理します。検索結果スナップショットはページキャッシュの期限と独立です。旧キャッシュは参照時に移行します。アプリのデータ消去・アンインストール時には失われます。ZZZSearchのWeb検索結果はこの履歴保存の対象外です。

### 保持上限の変更・バックアップ

同じ設定画面の「履歴・キャッシュの保持件数」から以下を数値指定できます。上記の容量・期間は初期値です。

- 履歴の保持件数、合計容量、1件の容量、1件の結果数、本文等の合計文字数。
- 取得ページキャッシュの容量と再利用期間（時間）。

0は無制限／無期限です。OS・空き容量・Javaの配列／JSON表現・メモリの限界は残ります。通信応答1件の2MiB安全上限と検索画面の最大2000件表示は別です。上限を下げると次の保存時に整理します。過去に省略・削除した結果は増量しても復元しません。無期限のページ再利用は更新の反映を遅らせるため、必要時にキャッシュを削除してください。

MEGA／ローカルZIPバックアップの対象に「ワッチョイ4桁検索の履歴・保存結果」と「ワッチョイ4桁検索の取得ページキャッシュ」を追加しました。どちらも初期オフで、個別選択して保存・復元できます。検索条件・本文を含むためバックアップの取り扱いに注意してください。上限設定自体も移行する場合は「ChMate・Haiagaruの設定」を選択します。旧版アプリはこの新しいカテゴリを含むZIPを復元できません。追加版の実機での保存・復元テストは接続切断で未完了です。

1.9.0では走査上限を最大10,000（初期100）とし、通信回数上限（0＝無制限）を別に指定できます。通信回数は開始／再開ごとのページ取得試行です。エッヂはスレ名指定時にKyodemoの検索一覧から取得し、本文の続きページも通信上限・再開位置へ反映します。
