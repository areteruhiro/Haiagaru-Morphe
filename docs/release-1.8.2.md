# Haiagaru 1.8.2 (Pre-release)

1.8.1からの変更点です。検証用プレリリースのため、更新前に大切な設定・NG登録・ログをバックアップしてください。

## ワッチョイ下4桁のNG登録を改善

- 「ﾜｯﾁｮｲ下4桁をNG登録」の通常タップで、NGName追加画面を開くようにしました。その場で「有効」「文字列／正規表現」「連鎖」「非表示（あぼーん扱いにしない）」「登録板」を選択できます。
- 文字列は `-aabb` のように新規登録します。正規表現では、新規登録のほか、同じ登録板・有効／連鎖／非表示設定の既存NGへ追記できます。追記先を選ぶことで、登録行が増え続けるのを防げます。
- 文字列と正規表現の登録方法の説明を、NG追加画面に表示します。
- このメニュー項目を**長押し**すると、下4桁を `-aabb|` の形式でコピーし、従来のNGName編集画面を開きます。末尾の `|` は正規表現への追記用の区切りです。手動編集では次の条件を続けるか、末尾の区切りを削除してください。
- 226 dev／242 devなどで長押ししても通常タップ扱いになる経路を修正しました。
- 191 devのメニュー描画でレジスタが再利用される場合にも対応し、今回の長押し処理によるクラッシュを防ぎます。
- 正規表現の追記時は条件を安全に結合し、末尾の空の条件を保存しないようにしました。

## ワッチョイメニューをNG優先の順番に変更可能

Haiagaru設定に「ワッチョイ長押しメニューをNG登録優先の順番にする」を追加しました。初期値はOFFです。

ONにすると、表示可能な項目を次の順番に並べます。

1. NGName に追加
2. ﾜｯﾁｮｲ下4桁でNGName登録
3. コピー
4. 取得済みのスレから検索
5. 必死チェッカーもどき(ﾜｯﾁｮｲ)

元から表示条件を満たさない項目は追加しません。既存の操作・アイコン・有効状態は維持します。

## NGName統合画面の表示を修正

- 「表示中のNGNameを下4桁でまとめる」で候補が多い場合に、「適用」「キャンセル」が画面外へ押し出される問題を修正しました。
- 「統合した元のNGNameを削除する」はリスト末尾に表示します。元の登録を削除するかどうかは引き続き選択式で、初期値はOFFです。

## 対応・更新方法

- 対象：`0.8.10.191 dev`／`0.8.10.226 dev`／`0.8.10.241`／`0.8.10.242 dev`。
- `0.8.10.243 dev`は引き続き非推奨です。今回の改善の対応対象には含みません。
- Morpheのプレリリース取得を有効にし、バンドル更新後、元のAPKへ再度パッチを適用してください。インストール済みアプリはバンドル更新だけでは変更されません。
- 正式版の取得先は変更しません。1.8.1以前の機能は引き続き含まれます。
- エミュレータでの確認結果は端末固有の動作を保証するものではありません。実験的な画像取得専用VPNや巨大バックアップ復元について、以前記載した検証範囲・注意事項も引き続き適用されます。

### 今回の検証範囲

- 公開用1.8.2 Android MPPから、191／226／241／242の元APKへのパッチ適用と生成APKのフック検査が通過しました。
- API 36エミュレータで、226／241／242は実際のスレ内メニューの長押しからNGName編集画面への遷移を確認しました。191はネイティブメニュー行の長押し処理と編集画面の表示を確認しました。
- 登録画面での保存、文字列／正規表現のフラグ、連鎖・非表示・登録板、既存正規表現への追記を確認しました。NG統合の多数候補時の画面修正は191の隔離テストで確認しています。
