# エッヂの関連・次スレ候補

Haiagaru設定 → 保存したレス・過去のスレ →「エッヂの次スレ検索に関連スレ候補も表示」をオンにします。初期状態はオフです。191／226／242 dev向けです。

標準の「次スレ検索」を開いた際に、エッヂの最新スレ一覧を取得し、同じ板で元スレより新しく7日以内に作成された候補を別の選択一覧で提示します。「ChMate」のような共通語で、タイトルが大きく変わった関連スレも拾います。候補は最大30件で、関連度が高い順です。

元スレが最新スレ一覧にない場合（DAT落ち等）は「関連・次スレ候補」と表示します。一覧にない理由までは断定しません。取得失敗をDAT落ちとは扱いません。候補は次スレの保証ではなく、自動移動・自動お気に入り登録は行いません。タップした候補だけを開きます。「標準の検索結果に戻る」でChMateの検索結果も確認できます。

板の公開スレ一覧のみを参照します。本文を追加取得する意味検索、過去ログ全体の検索、バックグラウンドの常時監視は行いません。
