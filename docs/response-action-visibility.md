# レスメニュー・ツールバーの表示

Compose版では、ChMate標準のツールバー設定で項目の表示チェックと順序を変更します。

本体設定の「標準設定／常に表示／常に非表示」の重複指定と、Haiagaru全体の表示スイッチは廃止しました。過去の強制表示指定よりも、ChMateのチェック状態を優先します。各ツールバーの保存済み配置順・チェック状態を上書きしません。

ワッチョイ上／下4桁検索をオフにしても検索画面への入口は残り、同じ画面でオンに戻せます。検索機能をオフにする設定と、ボタンの表示チェックは別です。

アイコン画像の変更は「Haiagaru設定 → スレを読む → ツールバーのアイコン画像」から行えます。[アイコンの案内](toolbar-icons.md)

この案内は開発中のCompose版に対応しています。公開済み1.9.3の画面とは異なります。[確認範囲](compose-settings.md)
