# 追加項目の表示設定（1.9.0）

Haiagaru表示設定に「レス長押し・ツールバー項目を個別設定」を追加。各項目を「標準のツールバー設定に従う／常に表示／常に非表示」から選べます。既存の配置順と保存済み標準設定は変更しません。表示設定のみで機能や保存データを削除しません。メニューを開き直して反映してください。

過去レスを見る・上4桁検索・下4桁検索・ﾜｯﾁｮｲで検索・投稿者を強調・レスを保存は、未設定の場合の初期表示をオフに変更。下4桁NG登録は従来の初期値を維持。保存済みの標準表示設定があれば優先し、明示的な個別設定があればそれを優先します。

スレ内ツールバーの上／下4桁検索も未設定時オフ。「ツールバー表示・追加アイコン」の対象を6項目へ広げ、上／下4桁の表示と任意画像も設定可能にしました。ツールバーは再起動後に反映します。
