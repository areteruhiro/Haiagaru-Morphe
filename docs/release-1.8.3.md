# Haiagaru 1.8.3 (Pre-release)

1.8.2からの変更点です。検証用プレリリースのため、更新前に設定・NG登録・ログをバックアップしてください。

## フィルタ切り替え時の位置維持

Haiagaru設定に「フィルタ切り替え時に表示位置を維持する」を追加しました。初期値はオフです。

- オンにすると、人気レス・リンク・画像・動画のフィルタ切り替えで、レス1へ戻らず表示中のレスと縦位置を維持するよう補正します。
- 表示中のレスが抽出対象から外れた場合は、元の並びで最も近い残存レスへ移動します。同距離なら後続のレスを優先します。抽出結果が空の場合は空の一覧を維持します。
- 元の上部フィルタと、ツールバーのフィルタの両方が対象です。オフにすると従来の動作になります。

## 191 devの下4桁NG登録を修正

- 「ﾜｯﾁｮｲ下4桁をNG登録」の通常タップで、NGName追加画面が開かないポップアップ経路を修正しました。
- 長押しは引き続き、下4桁をコピーして標準NGName編集画面を開きます。

## NGの対象板を複数指定・除外指定

- 「全板共通」「選択した板のみ」「選択した板以外すべて」から対象を選べます。除外指定では、後から追加された板も除外対象でなければ適用されます。
- 板はチェックボックス形式で複数選択でき、選択するたびに画面が閉じることはありません。
- 下4桁NG追加画面のほか、Haiagaru設定の「登録NGの検索・板別表示・ﾜｯﾁｮｲ統合」で、既存のNG項目をタップして対象板だけを変更できます。NG文字列・各フラグ・登録日時は保持します。表示中のスレは開き直してください。
- **互換性の注意：** 複数板・除外板の新形式は、今回の補正がない旧パッチ／未パッチのChMateでは機能しません。旧環境へ戻す場合は、先に全板または単一板へ変更してください。

## 対応・更新方法

- 対象：`0.8.10.191 dev`／`0.8.10.226 dev`／`0.8.10.241`／`0.8.10.242 dev`。
- `0.8.10.243 dev`は引き続き非推奨で、今回の追加機能の対象外です。
- Morpheのプレリリース取得を有効にし、バンドル更新後、元のAPKへ再度パッチを適用してください。インストール済みアプリはバンドル更新だけでは変更されません。
- 正式版の取得先は変更しません。

## 検証範囲

- 公開用Android MPPのビルド、4バージョンへのパッチ適用、生成APKのフィルタ・NGフック検査を実施しています。
- フィルタ位置選択の9ケースと、NGの文字列／正規表現、通常タップ／長押し、対象板の含む／除外する判定の回帰テストを実施しています。
- NGの直接判定・キャッシュ判定はAPI 36エミュレータの隔離アプリで4バージョンを検証しました。191の追加画面と242の既存NGワードの対象板変更も確認しています。
- **新しいフィルタ位置維持の画面上の動作と、Morpheでの取得表示は未確認です。** 上記のビルド・適用・ロジック検査は、実機での表示確認を代替するものではありません。
