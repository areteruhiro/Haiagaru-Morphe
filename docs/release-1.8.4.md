# Haiagaru 1.8.4 (Pre-release)

1.8.3からの変更点です。検証用プレリリースのため、更新前に設定・NG登録・ログをバックアップしてください。

## Imgurログインアップロード（開発中）

パッチ適用時に選べる独立オプションを追加しました。**初期状態は未選択**です。

1. Morpheで「Imgurログインアップロード（開発中）」を選び、パッチを適用します。
2. Haiagaru設定の「Imgurにログイン／Webアカウント送信（開発中）」を開きます。
3. アプリ内のImgur画面でログインし、「確認・有効化」を押します。
4. 既存のImgurアップロード操作から、ログインしたアカウントに画像を送信できます。

- Imgur自身のログインに加え、Google認証画面への遷移とログイン用の別ウィンドウをWebView内で開けます。ただし、Google側で埋め込みブラウザを拒否される場合があり、ログイン成功を保証するものではありません。
- Chromeなどの外部ブラウザとはログイン状態を共有しません。外部ブラウザのCookieを読み取る機能ではありません。
- 送信前と送信結果のアカウントを確認します。有効時に失敗しても匿名送信へ切り替えず、自動再送もしません。タイムアウトなどの後は、再送前にImgurの画像一覧を確認してください。
- パッチオプションを選ばなければ設定項目を表示せず、以前の有効化設定が残っていてもWebアカウント送信は動作しません。
- 非公式のWeb方式による開発中の機能です。Imgurの仕様変更や利用制限で停止する可能性があります。利用規約・料金条件が適用され、無料利用や商用利用の許諾を保証するものではありません。

## 191 devの下4桁NG登録を追加修正

- 「ﾜｯﾁｮｲ下4桁をNG登録」の通常タップでNGName追加画面が開かない問題を修正しました。長押し用のメニュー行が通常タップを吸収していたため、本来のメニュー処理へ渡すようにしました。
- 長押しによる従来のNG編集画面への移動は維持しています。
- メニュー行が再利用される場合にも、別の項目へリスナーが残らないようにしました。

## 対応・更新方法

- 今回の機能の対象：`0.8.10.191 dev`／`0.8.10.226 dev`／`0.8.10.241`／`0.8.10.242 dev`。
- `0.8.10.243 dev`は引き続き非推奨で、今回のImgurオプションの対象外です。
- Morpheのプレリリース取得を有効にし、バンドル更新後、元のAPKへパッチを適用し直してください。
- 正式版の取得先は変更しません。

## 確認済みの範囲と未確認の範囲

- 公開用1.8.4 Android MPPから4バージョンへのパッチ適用と、生成APKのImgur・NGメニューフック検査が通過しています。
- API 36エミュレータの191でログイン後、既存アップロードラッパー経由でテストPNGを1枚送信しました。送信結果の所有者確認に加え、ログインアカウントの画像一覧にも存在することを確認しました。掲示板への投稿は行っていません。
- 191のNG通常タップ／長押し、メニュー行の再利用、ログイン用ウィンドウの開閉と遷移先制限を確認しています。
- **画像選択から本文へのURL挿入までの画面操作一式、動画の実アップロード、他バージョンでの実アカウント送信、長期間のログイン維持は未確認です。** 全端末での動作を保証するものではありません。
