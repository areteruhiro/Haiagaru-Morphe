# 既読スレをまとめて削除

対応: ChMate 0.8.10.191 dev／226 dev／242 dev。通常表示・タブレット表示で利用します。

## 開き方

- 板のスレ一覧の更新ボタンを長押しします。短押しは従来どおり更新です。
- またはChMateの「設定 → ジェスチャー」で「既読スレをすべて削除」に未使用のジェスチャーを割り当て、板のスレ一覧上で操作します。初期状態では未割り当てです。

## 確認と削除

1. 操作した板の一覧にある、取得済み・未読0件のスレがチェック一覧に表示されます。未取得・未読が残るスレは候補に含めません。
2. 各行をタップしてチェック／解除します。「すべて選択／すべて解除」でも切り替えられます。
3. 「削除（件数）」を押すと、選択したスレの履歴と取得済みログをChMate標準の削除処理で削除します。キャンセルすると何も削除しません。

タブレット表示でも、別の板や右側のスレ本文の履歴をまとめて削除する動作ではありません。
確認画面を開いた後で新着が届くなど、未読状態が変わったスレは削除直前に除外します。

削除は元に戻せません。必要なログは先にバックアップしてください。保存済みアーカイブやレス保存スレは対象にしません。
掲示板サーバー上のスレ自体は消えないため、板を更新すると未取得のスレとして再び表示されることがあります。

Haiagaru 1.8.13で追加しました。

## 検証状況

191／226／242のパッチ済み検証アプリで、合成データを使った確認画面の13項目（個別チェック、全選択・解除、0件時の無効化、キャンセルなど）を確認済みです。選別ポリシー15項目と、各版の削除API・ジェスチャー・長押しの組み込みも検査しています。
実際の板一覧からジェスチャー／更新長押しを経由してログを削除する通し確認と、タブレットの左右ペインでの確認は未完了です。実データを削除した検証ではありません。
