# 5chのIDなしレスを非表示

191 dev／226 dev／242 dev対応。初期状態はオフです。

「Haiagaru設定 → NG・省略 → 5chのIDなしレスを非表示」を開き、チェックして保存します。
保存後は対象スレを閉じて開き直してください。オフにすると、この機能による非表示は解除されます。
通常のNG登録・高度なNGルールは変更しません。

5chの[公式Wiki（BBS_SLIP）](https://info.5ch.net/index.php/BBS_SLIP)には、
IDを非表示にする `!id:none` と、ID・SLIP表示を抑える `!id:ignore` が記載されています。
ただし、取得したレス情報だけで、投稿者が意図的にIDを消したかを確定することはできません。

このため、取得済みの同一スレに通常のIDがある場合に限って、IDが空欄または `???`／`???0` 等のレスを非表示にします。
「あぼーん」の行も残さない扱いです。まだID付きレスを取得していない段階や、全レスIDなしのスレでは隠しません。
削除済みレス（`ID:DELETED` はID非表示とは異なります）、システム投稿、★付き投稿はこの機能の対象外です。

対象ホストは `5ch.io`／`5ch.net` とそのサブドメインです。
Talk・エッヂなど他掲示板、元スレを確認できないデータには適用しません。
DATや書き込み内容を削除する機能ではなく、表示時のNG判定です。
