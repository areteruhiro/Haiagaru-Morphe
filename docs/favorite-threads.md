# ★スレタブ

複数の板で★を付けたスレを、HOMEの「★スレ」にまとめます。★1以上が対象です。別のお気に入り登録は不要で、★を外すと一覧からも外れます。

通常の「スレ」との違いは、お気に入りだけに対象を絞ることです。未読の有無にかかわらず、★を付けたスレを板横断で確認できます。

アプリ内の説明文：

> ★スレのみ巡回

ツールバー設定の項目説明と、★スレ選択時のHOME説明表示にこの短い文を使用します。ボタン名は「★スレ」のままです。更新時は★付きスレだけを巡回します。

HOMEのツールバー設定で「★スレ」を表示できます。このタブで更新ボタンを押すと、ChMate標準の「お気に入りのみ」の巡回を開始します。通常の未読・スレ・履歴タブの絞り込み設定は変更しません。
