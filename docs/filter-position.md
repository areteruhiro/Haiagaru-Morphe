# フィルタ切り替え時の表示位置

Haiagaru設定の「フィルタ切り替え時に表示位置を維持する」で切り替えます。
初期値はオフです。オフではChMate本来の動作を変更しません。

- 対応: 0.8.10.191 dev / 226 dev / 241 / 242 dev。
- 元の上部フィルタと、ツールバーのフィルタの両方が対象です。
- オンでは切り替え前に見えていたレスと縦位置を基準にします。
- そのレスが抽出対象から外れた場合は、元の表示順で最も近い残存レスへ移動します。
  同距離なら後続のレスを優先します。該当レスがなければ空の一覧を維持します。
- 位置維持はフィルタ操作時だけ実行します。読込・検索・自動リロードは変更しません。
- 非同期の一覧更新を描画前に確認し、一度だけ位置を復元します。
  画面破棄・アダプタ差替え・3秒の期限で待機を解除します。

検証用: `scripts/VerifyFilterPositionAnchor.java` はAndroid不要の位置選択テストです。
