# スレを開くと終了する問題とタブ復帰時の再読込

## 対象と更新

1.10.0-dev.3の191 devで、スレを開いた直後にアプリが終了する問題を修正しました。ログには `VerifyError`、`o.pa.onResume()`、`register v0 has type Boolean but expected Reference java.lang.Object` が記録されます。設定のオン／オフではクラスの検証エラーを回避できません。

修正版パッチを取得し、元の未改変ChMate APKへ適用してください。設定・履歴の初期化は不要です。アプリを上書き更新する場合は、同じパッケージ名と署名鍵を使用します。

## 191／226／242共通の操作

Haiagaru設定 →「アプリ・通信」の通信設定にある「タブレットでスレ切替時の自動再読込を抑える」を変更します。初期値はオンです。スレ切替だけで復帰した場合の自動再読込を抑えます。初回の本文読込、更新ボタン、アプリ自体をバックグラウンドから戻した際の処理はChMateに従います。オフにすると復帰時の自動再読込もChMateに従います。

191／226／242の元APKごとに自動再読込の呼び出しを特定し、別メソッド内で抑制を判定します。呼び出し元のレジスタ、引数、分岐、戻り値を維持し、最初の空の本文を読み込む処理とは分離しています。241／243はバンドル全体の配布対象外です。

検証結果と残る制限は[正式版の案内](release-1.10.0.md)を参照してください。
