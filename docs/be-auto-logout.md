# スレ立て時のBE自動ログイン／成功後ログアウト

Haiagaru設定 → 書き込み → 「5chのスレ立て時にBEへ自動ログイン／成功後ログアウト」で切り替えます。初期状態はオフです。191 dev／226 dev／242 dev向けです。事前にChMate標準設定へBEのログイン情報を保存してください。

オンの場合、5chの新規スレ立て送信直前に、保存済みのBE情報を使ってChMate標準の認証処理でログインします。ログインが完了するまで送信せず、認証失敗・未設定の場合は送信を中止します。通常の返信、他の掲示板、編集画面を開いただけの場合は自動ログインしません。

スレ立てが成功した後、ChMate標準のBEログアウト処理をバックグラウンドで実行します。スレ立て失敗時は再試行用にログイン状態を維持します。この場合は通常レスにもBEが付く可能性があるため、返信前に手動でログアウトしてください。保存したBEのメールアドレス・パスワードやUPLIFTのログイン情報は削除しません。

ログアウト完了または失敗を通知します。通信に失敗した場合、ログインが残る可能性があるため手動でログアウトしてください。次の投稿は完了通知を確認してから行ってください。

1.8.14で追加しました。Androidビルド、191／226／242へのパッチ適用、各APKのスレ立て専用ログインフック・編集画面登録・成功後ログアウトフック・版別のBE処理と板URL取得先の接続検査に合格しました。
