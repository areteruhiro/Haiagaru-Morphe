# 動画専用ビューア（1.8.6プレリリース）

次回更新より、パッチ適用時に「動画専用ビューア」を選択して導入する（初期状態は未選択）。
導入後はHaiagaru設定の「動画を専用ビューアで開く」で切り替える。設定の初期値はオン。
パッチ未選択または設定オフならChMate従来の起動先を変更しない。
以前の設定がオンでも、パッチを選ばずに作り直したAPKでは有効にならない。
未導入時は設定スイッチを無効化し、導入方法を表示する。

この機能はAndroid標準VideoViewを使い、大容量の動画デコーダーを同梱していない。
パッチの選択式化は機能の導入可否を制御するもので、バンドルの大幅な容量削減にはならない。

## 選択式パッチの検証（未公開）

- 191の選択あり／なしAPKを作成し、`VerifyVideoViewerOption`で導入マーカーと
  設定・Activity入口のガードを検証。aapt2で未選択APKにはActivity登録がないことも確認。
- エミュレータの分離した検証用アプリで、選択ありは有効、未選択APKへの上書き後は
  保存済みオン設定が残っていても無効になること、外部動画Intentを変更しないことを確認。
- バンドル全体は約31.5MiB。圧縮後の主な内訳はVPNネイティブライブラリ12.58MiB、
  絵文字フォント9.50MiB、TFLiteライブラリ6.86MiB、その他2.53MiB。
  容量削減のために既存機能や対応ABIを削除する変更は行っていない。

- 対象: 191 dev / 226 dev / 241 / 242 dev。
- 添付対応済みのImgur・X・Instagram配信元のHTTPS MP4を対象とする。
  アルバムURL自体ではなく、解析後の直接動画URLを開く。
- AndroidのVideoViewを使用し、再生・一時停止・シークを提供する。
  動画タップ後にストリーミング通信を行う。ログインCookieは渡さない。
- ︙: 外部アプリで開く、URLコピー、再読み込み、画面回転。
- タイトル文字は表示しない。「戻る」「︙」はシークバーと同時に表示・非表示にする。
  画面タップで切り替え、自動非表示タイマーは使用しない（シーク・再生操作後も同じ）。
  動画の表示位置・サイズは変えない。ボタン背景は透明で、白文字に黒い影を付ける。
- 他アプリへ移動した場合は一時停止し、戻っても勝手に再生しない。
- エラー時はエラー番号と再読み込み／外部アプリへの案内を表示。
  自動リトライやバックグラウンド再生は行わない。
- ステータスバー・ナビゲーションバーのInsetsを反映する。
- Activityはexported=false、外部アプリからの直接起動を許可しない。
- ネイティブのstartActivity/startActivityForResult境界だけに接続する。
  明示的な別画面指定・対象外URLは維持し、専用ビューア自身の外部起動は再介入しない。

## ジェスチャー対応（未公開）

ChMate設定の割り当てと全体オン／オフ、判定距離を共有する。
APK内の認識器を検出して使用し、独自の固定スワイプ設定は追加しない。

- 戻る／タブを閉じる: 動画画面を閉じる。
- 先頭／末尾: 動画の先頭／末尾へシーク。
- 更新: 現在位置を保持して再読み込み。
- 全画面: 操作パネルの表示切り替え。
- 設定／NG編集: ChMateの該当画面を開く。
- 進む: 次の動画がない旨を表示（単一動画画面に履歴はない）。

スレ削除・書き込み等、動画に対応しない操作は実行しない。
上部ボタンと別ウィンドウのMediaControllerにはジェスチャーを介入させない。
動画上のタップも従来の操作パネル表示切り替えを維持する。

`VerifyVideoGestureProfile.java`で原本191 / 226 / 241 / 242の認識器と距離設定メソッドを確認。
191の分離した検証アプリではネイティブ起動経路から動画を開き、実際のADBスワイプから
「戻る」により閉じることを確認。`frida-video-gestures-regression.js`でタップによる
誤実行なし、全体OFF、「先頭」「戻る」の割り当ても確認。
226 / 241 / 242の実画面での操作は未検証。

## 検証

`VerifyVideoViewer`で4APKの専用Activity、設定、外部メニュー、
startActivityForResultを含む接続を確認した。
Manifestには非公開Activityと回転時のconfigChanges登録を確認した。
ランタイム検証は`scripts/frida-video-viewer-fixture.js`で行う。

191のエミュレータで、通常のサムネイルタップと同じネイティブヘルパーから
内部ビューアが開くこと、指定されたImgur動画の再生（約9.8秒）、
オン／オフと対象外URLの振り分け、︙の4項目、外部動画アプリへの起動を確認した。
再生中のホーム移動後に`playing=false / foreground=false`となることも確認した。
既存アプリはデータ保持で上書き。アップロード・削除・ログイン操作は行っていない。
226/241/242の実再生は未検証（APK適用と静的検証のみ）。
検証ログ: `video-viewer191-runtime.log` / `video-playback191.log` / `video-viewer-static.log`
（いずれもbuild/verification配下）。
