# Haiagaru設定の使い方

設定の入口から、変更したい内容を選びます。「画像・動画を見る」と「画像・動画を投稿する」は別の項目です。Xの投稿表示も独立しています。

設定名が分からないときは「文字」「画像」「NG」などで検索すると、一致する設定項目が個別に表示されます。項目の下に所属カテゴリが表示され、タップするとその設定へ移動します。戻る操作で検索結果へ戻れます。検索結果からさらに戻ると検索を解除します。入力済みの値や認証情報は検索対象に含めません。

カテゴリを開くと、そのカテゴリの設定だけが表示されます。「戻る」または端末の戻る操作で直前の画面へ戻ります。別の設定ダイアログを閉じると元のカテゴリが表示されます。「画面・文字の表示」から行間やボタンなどを変更できます。

スイッチや選択肢は変更するとすぐに保存されます。数値は表示された範囲の有効な値を入力すると保存され、入力途中の空欄や範囲外の値では以前の設定を維持します。「保存して閉じる」はありません。ボタンから開く別画面は、その画面の操作に従ってください。

最初に開くのは軽量なカテゴリ一覧だけです。設定部品は選んだカテゴリだけを作り、同じ画面へ戻る際は再利用します。保存は非同期で行い、設定変更によるアプリの強制再起動はしません。一覧や通信に関する設定は次の一覧表示・通信から反映されます。

検索するときだけ各カテゴリを順番に読み込み、個別項目を探します。入力中は検索開始を少し遅らせ、文字を入力するたびに全画面を作り直さないようにしています。

通信などの専門的な設定は「通信・詳しい設定」にあります。分からない設定は変更しなくても利用できます。

この変更で既存の設定値や保存形式は変わりません。191／226／242で共通の画面構成を使用します。
