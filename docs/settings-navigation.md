# Haiagaru設定の使い方（Compose版）

最初の画面から、変えたいことを選びます。

- 読む：文字・一覧・コピー・Xプレビュー。
- 探す・過去ログ：IDチェッカー・DAT取得・保存レス。
- 書き込む：入力・送信・画像や動画の投稿。
- 画像・動画：再生・サムネイル・保存。
- NG・ミュート、履歴、バックアップ、アプリ・通信はそれぞれ独立しています。

カテゴリの中では関連項目をまとめて表示します。設定一覧の検索は、項目名を探してその場で操作できます。変更は自動保存し、必要な場合だけ再起動を確認します。戻る操作ではカテゴリから一覧へ戻ります。ChMateの戻る・閉じる・先頭／末尾ジェスチャーも利用します。

ツールバーの表示・配置はChMate標準のツールバー設定、投稿検索のオン／オフや履歴保存は検索画面で変更します。本体設定には同じ入口・表示スイッチを重ねません。

[8カテゴリの詳細・確認範囲](compose-settings.md) ／ [機能ごとの設定場所](feature-switches.md)
