# 追加機能のオン／オフ（1.9.0）

Haiagaru設定 → 一般 →「追加機能のオン／オフ一覧」。閲覧・一覧11、保存・投稿2、検索4、画像・動画9、Xプレビュー6、通信2の計34項目。既存カテゴリと同じ設定キーを使い、過去の設定値を維持する。

新規停止設定はレス保存、4桁検索、スレ立てコマンド候補、動画フレームサムネイル生成。オフで新規処理を抑止し、保存済みデータは削除しない。サービス検索をオフにした場合は実行中のサービスワーカーもcancelする。foreground検索は次の取得前に設定を確認。すでに通信中・ネイティブ解析中の処理をすべて即時中断する保証はなく、一部は終了まで継続する。

項目別レスメニュー表示には「標準設定／常に表示／常に非表示」を提供。追加6項目の初期表示はfalseで、既存の保存値・配置順を維持。242のシートも表示判定へ接続。

これは全機能の全経路を完全無効化するマスタースイッチではない。NG・投稿者強調・コピー履歴・バックアップ／同期・巡回画像保存・アップロード先・外部板ごとの認証・画像取得VPN等は各専用設定／任意パッチ選択を引き続き使う。数値カスタマイズは標準値へ戻す方式のものもある。クラッシュ回避・検証・パス制限など安全対策は常時有効。

画面・メニューを開き直して反映。ネイティブツールバーは再起動が必要な場合あり。34項目の共通キー／初期値と6項目の初期オフをテストし、実画面で全経路を検証したとは扱わない。実機への追加版インストールと公開は別途。
