# Haiagaru 1.8.15 (Pre-release)

1.8.14からの変更です。ChMate 0.8.10.191 dev／226 dev／242 devに対応します。

## 更新内容

- HOMEに、板をまたいでお気に入りのスレをまとめる「★スレ」タブを追加しました。HOMEのツールバー設定から表示でき、更新ボタンでお気に入り対象の巡回を開始します。[使い方](https://github.com/areteruhiro/Haiagaru-Morphe/blob/master/docs/favorite-threads.md)
- 「投稿者を強調」で登録対象ごとに背景色を選べるようにし、色を12色へ増やしました。登録一覧から個別変更もできます。既存登録は従来の共通色を維持します。
- 更新／巡回ボタンが反応しなくなる問題への補正を191／226／242すべてへ適用しました。共用Viewのタップを吸収する処理を廃止しています。更新ボタン長押しの既読スレ削除は、Haiagaru設定 → 画面・文字の表示からオン／オフできます（初期オン）。削除ジェスチャーは独立して使えます。
- 外部板の名前／URL編集画面に、板名・URLの部分一致検索を追加しました。英字の大小を区別せず、検索欄を空にすると全件表示へ戻ります。「BBSMENUの板も表示」と併用できます。
- 「過去レスを見る」「レスを保存」のアイコンをMaterial Iconsのベクターへ変更しました。通常のレスメニュー、242のシート、メニュー表示設定に反映します。
- 分割プレビューの対象時間を、分・秒別々の欄から1つの「分:秒」欄へ変更しました。例：`1:30` は1分30秒以上、`0:00` はすべての動画です。従来の設定値は維持します。
- ローカル自動バックアップを追加しました。保存先・実行間隔・保持件数・保存対象を選べます（初期オフ）。起動・復帰時と、開いている間は約1分ごとに期限を確認し、必要なら保存します。MEGA不要です。[操作・重要な注意事項](https://github.com/areteruhiro/Haiagaru-Morphe/blob/master/docs/local-auto-backup.md)
- 長押しコピー中の `>>番号` の操作をChMate標準へ渡す設定を追加しました。「画面・文字の表示 → 長押しコピー中も >>番号の長押し操作を優先」で切り替えられます（初期オン）。オフでは番号も範囲選択を優先します。行の再表示で選択用設定が上書きされる場合への補正と、選択が始まらない長押しの再試行も追加しました。
- ローカルのバックアップ・復元処理中に進捗画面を表示し、失敗内容をログへ残すようにしました。

## 注意事項

ローカル自動バックアップのZIPは暗号化されません。Cookie・認証情報・端末依存データ等は初期オフです。保持件数を超えた、この機能が記録した古いバックアップは、新しい保存の成功後に**完全削除**します。重要なZIPは別の場所にもコピーしてください。バックグラウンド・終了中は新規実行せず、開始済みの保存は続行します。Androidによるプロセス終了で中断される場合があります。

既読スレ削除は未読が残るスレも対象です。確認画面で対象を確認してください。削除した履歴・ログは元に戻せません。

正式版の取得先は1.7.1のまま維持します。
