# スレ内のレスフィルター

開発中の追加機能です。公開済みのバンドルにはまだ含まれません。

スレ内のフィルター行と、ツールバーの「フィルタ」で同じ7項目を選べます。

| 項目 | 対象 |
| --- | --- |
| 人気レス | ChMateの人気レス設定に従うレス。人気レスのポップアップ設定を使用している場合は、その閾値で集計します。 |
| リンク | ChMateが画像・動画に分類しないリンクを含むレス |
| 画像 | ChMateの画像判定に該当するリンクを含むレス |
| 動画 | ChMateの動画判定に該当するリンクを含むレス |
| AA | ChMateがAAと判定したレス |
| 自分 | ChMateで「自分の書込み」の印が付いているレス |
| 返信 | 「自分の書込み」のレス番号に直接アンカーを付けたレス |

数字は読み込み済みの全レスを対象にした件数です。1つのレスに複数の画像・リンク・アンカーがあっても、同じ項目では1件と数えます。複数項目に該当するレスは、それぞれの項目で数えます。条件をオフにしていても件数を表示します。追加取得の通信は行いません。

AA・自分・返信を複数選ぶと、そのいずれかに一致するレスを表示します。既存の人気レス・リンク・画像・動画と組み合わせる場合は、既存の絞り込み結果に追加で適用します。スレの更新後は再集計し、フィルター行と開いているツールバー一覧の数字を更新します。

画像の長押しで画像一覧を開く操作と、人気レスのポップアップ設定は維持します。フィルター行を隠す設定がオンの場合は、ツールバーのフィルターから操作します。

判定に使う「自分の書込み」の印はChMate側の記録です。同じIDの別のレスや、投稿本文が似たレスを自分と判定することはありません。印のない過去の投稿への返信は対象に含まれません。

表示用リストだけを絞り込み、DAT・NG設定・自分の書込みの印・既読数は書き換えません。191／226／242 devで共通の操作を追加します。実機動作確認の結果は統合記録を参照してください。
