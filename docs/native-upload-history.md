# ChMate標準の画像アップロード履歴

対象: 0.8.10.191 dev / 0.8.10.226 dev / 0.8.10.242 dev。
通常のHaiagaruパッチに含まれ、開発中のImgurログインパッチは不要です。

標準「画像アップロード履歴」右上の︙に追加します。

- **新しい順（降順）**: 日時の降順に表示。再度選ぶと標準順に戻ります。設定は保存されます。保存ファイル自体の順序は変更しません。
- **サーバーから一括削除…**: チェックボックスで選択し、確認後に削除。全選択／解除と中止が可能です。

サーバー削除は取り消せません。削除キーのない履歴・削除済みの履歴は対象外です。
成功した画像は標準機能と同じ削除済みフラグで記録し、失敗した画像は変更しません。
中止時は処理中の1件の結果を保存し、次の画像から停止します。
通信はワーカースレッドで、ChMate標準のサーバー削除処理を利用します。
ログへ削除キーや認証情報は出力しません。

191は標準Menu／Adapter、226／242は標準Composeの︙と表示用StateFlowへ追加します。
Composeの追加項目は標準のメニュー行と文字描画を使い、標準項目の文字は変更しません。

検証スクリプト: `scripts/frida-native-upload-history-test.js`。
専用検証パッケージ以外では実行できません。削除要求は模擬応答に置換し、実サーバーの画像は削除しません。

検証記録: 3版へのAPKパッチ適用と、各版の標準︙への表示を確認。
191では20項目、226では21項目（標準ファイルの保存／再読込を含む）、242では18項目の実行検証を実施しました。
226は実際のComposeメニューのタップで降順の切替と一括削除の選択画面への遷移も確認しました。
確認後、選択ボタンは表示直後から操作できるよう同期的に接続しています。
