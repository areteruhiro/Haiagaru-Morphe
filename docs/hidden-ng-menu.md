# 「非表示NGを表示」を隠す

対象：ChMate 0.8.10.191 dev／0.8.10.226 dev／0.8.10.242 dev。

Haiagaru設定 →「NG・省略」→「右上メニューの『非表示NGを表示』を隠す」をオンにします。
初期状態はオフです。設定を保存後、次にスレのメニューを開く際に反映します。

隠すのは件数付きのメニュー項目のみです。NG登録、連鎖・非表示設定、レスの表示状態は変更しません。
オフに戻すとChMate標準の条件に従って表示されます（対象レスがない場合などは表示されません）。

各版のNG件数を設定するネイティブメニュー準備処理の終了時に、対象のMenuItemだけを非表示にします。
項目自体は削除せず、ネイティブ側のfindItemや件数更新を維持します。他のメニュー項目は変更しません。
