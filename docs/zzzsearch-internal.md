# ワッチョイ4桁検索とZZZSearch

Hissiの一致結果に並ぶ「未取得スレを開く」には、取得した投稿者ページに掲載されているスレ名と各書き込み本文も表示します。追加のスレ取得は行いません。本文が掲載されていない旧形式ではスレ名とリンクを表示し、本文未掲載と案内します。

検索画面の絞り込み文字は任意で、1〜4文字の部分一致や `abcd-efgh` の全体指定ができます。空欄ならHissiは選択した板・日付範囲内の投稿者を、エッヂは指定したスレ件数内の投稿IDをすべて走査します。Hissiでは上側／下側の選択が部分一致に使われます。

ZZZSearchのJavaScriptによる検索結果をそのまま表示します。「戻る」でページ履歴を戻り、履歴がなければ検索条件画面に戻ります。「外部で開く」でブラウザにも切り替えられます。スレURLのリンクはAndroidのURL連携に渡します。

Hissi用の板選択・日付範囲はZZZSearchへ自動適用しません。サービスの検索対象・収録状況に依存し、4桁一致を保証するものではありません。サイト内で結果を確認してください。

「スレ名だけで検索」「書き込み内容だけで検索」のボタンから、絞り込み文字なしで個別に検索できます。2つの条件とワッチョイ文字を組み合わせた検索もできます。スレ名は `intitle:"キーワード"`、書き込み内容は通常の全文検索条件として渡します。本文だけの厳密な照合ではなく、検索サービスのインデックスに依存します。取得済み／未取得のどちらも、収録されていれば対象です。

エッヂ検索はKyodemoの過去ログ板一覧を巡回し、投稿に付いた `ID` を照合します。絞り込み欄には `/GNQXmAUz` または `ID:/GNQXmAUz` を入力できます。空欄ならIDを指定せず投稿を走査します。板一覧をページ送りし、各スレの50レス単位の続きページも読み込みます。通信間隔は最低10秒で、指定したスレ件数の上限に達した場合は続きから再開できます。エッヂ検索の開始ではZZZSearchへ切り替えません。

絞り込み欄が空でスレ名または書き込み内容を入力した場合、Hissiの開始ボタンからはZZZSearchへ切り替えます。エッヂの開始ボタンは常にKyodemoを走査します。

エッヂ開始では、スレ名欄と書き込み内容欄をKyodemo上でAND照合します。本文欄だけでも検索できます。本文は各レスの本文部分だけを対象にし、ID・投稿日時・ページメニューは除外します。空白区切りの複数語はすべて含むレスが対象です。過去ログ検索のチェックを外すと現行スレを走査します。条件は履歴とバックグラウンド検索にも引き継ぎます。

Haiagaru設定の「ワッチョイ4桁検索：バックグラウンド・表示設定」内に「ZZZSearch関連を表示」「エッヂ関連を表示」を追加。個別にオフにして検索画面を開き直すと該当ボタン・専用項目を非表示にします。両方オフでは共通キーワード欄も非表示になります。
Kyodemoは一覧にスレが残っていても、投稿ページが「Dat not found」で404になる場合があります。そのスレまたは続きページは未収録として件数を表示し、次のスレへ検索を続けます。403・429・サーバーエラー、および板一覧自体の取得失敗では検索を中断します。

走査上限の初期値は100、最大10,000です。Hissiは一覧ページ数、エッヂはスレ件数として扱います。エッヂは一覧を1ページずつ読み、掲載スレの走査を終えてから次の一覧へ進みます。上限到達後も「続きから検索」で再開できます。

走査上限はHissi・エッヂともに1〜10,000（初期値100）です。0＝無制限は使用しません。スレ名が入力されている場合、Kyodemo板検索の `?bs=&kt=k_&fr=&to=&k=...` から一覧を取得し、検索語付きの次ページをたどります。日本語の検索語はサイトのフォームに合わせてShift_JISでエンコードします。現行スレ指定時は `kt` を空にします。

通信回数上限は0（初期値）で無制限です。開始／再開ごとにネットワークへのページ取得試行を数え、上限に達する次の取得を止めます。404も試行に含み、キャッシュの再利用は数えません。条件は履歴へ保存します。エッヂの続きレスページも再開位置として保持します（同一プロセス内）。
