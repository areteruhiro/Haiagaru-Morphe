# Haiagaru 1.7.91 (Pre-release)

## 1.7.9からの修正

- 「ワッチョイ下4桁でNGName登録」を押しても登録画面が開かない問題を修正しました。ChMate独自のポップアップから追加項目のクリックが登録処理へ渡るよう補正しています。191 dev／226 dev／241／242 devが対象です。
- フィルターの「画像」を長押しして開く画像一覧にも、追加メディア取得で解決済みのImgurアルバム・X・Instagramなどの画像を含めるようにしました。スレ本文からURLを抽出し直す際も同じメディア展開処理を使います。元の本文は書き換えず、既存のNG除外・重複除去・画像判定は維持します。

メディア取得設定や配信元の制限は従来どおりです。非公開投稿や取得に失敗した画像を表示できるようにする変更ではありません。

## 対応版

ChMate 0.8.10.191 dev／0.8.10.226 dev／0.8.10.241／0.8.10.242 dev。
0.8.10.243 devは非推奨で、今回の修正対象には含めていません。

正式版の取得先は変更せず、プレリリース版の取得先のみ更新します。

## 検証状況

- 4版の元APKへのパッチ適用と、生成APK内のNGメニュー・画像一覧の補正処理を確認。
- NGメニューのクリック通知、下4桁の判定、名前メニュー、Imgur・X・Instagramの解析テストを実施。
- 191のNG登録は実機でFridaによる同等補正後の反映を確認しました。今回生成したAPKでの実機再確認、画像一覧の実機表示確認は未実施です。
