# 動画ビューアの操作

対象：191 dev／226 dev／242 dev。「動画専用ビューア」パッチを選択して適用します。

Haiagaru設定の「動画ビューアの操作・YouTube設定」、または動画の︙→「操作設定」から変更できます。

- 左半分の上下スワイプ：上で明るく、下で暗く（このビューアの画面だけ）。
- 右半分の上下スワイプ：上で音量増、下で音量減（端末のメディア音量）。
- 左ダブルタップ：指定秒数巻き戻し、右ダブルタップ：指定秒数早送り。
- 秒数：5／10／15／30／60秒。先頭・末尾を超えない範囲に調整します。

3操作はそれぞれオン／オフ可能で、既存操作を維持するため初期値はオフです。
有効にした側の縦スワイプはChMateの縦ジェスチャーより優先します。
横方向のChMateジェスチャー、ツールバー、シークバーの操作は維持します。
画面1回タップで操作パネルを表示／非表示にし、自動では消しません。
操作説明の常時表示は行いません。システムの戻る操作は、パネルの表示状態に関係なく1回で動画ビューアを閉じます。

## YouTube

同じパッチでYouTube動画URLをアプリ内の公式埋め込みWebプレーヤーで開けます。
動画専用ビューア全体のオフ、または「YouTubeをアプリ内の公式プレーヤーで開く」のオフで従来の起動経路に戻ります。
watch／youtu.be／shorts／live／embed形式に対応し、プレイリストやチャンネルは対象外です。

YouTubeは公式プレーヤー側の操作を使用し、上の独自スワイプ・ダブルタップは適用しません。
公式プレーヤーの案内文は表示しません。システムの戻る操作は、全画面表示やページ履歴があっても1回でビューアを閉じます。
動画ファイルの抽出・ダウンロードや、広告・認証・地域制限・埋め込み禁止の回避はしません。
WebViewや配信元の条件により再生できない場合は︙→「YouTubeサイト表示」または「外部アプリで開く」を使ってください。
