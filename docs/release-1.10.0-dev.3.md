# 1.10.0-dev.2からの変更

## 表示と操作

- YahooニュースなどのWebサイトを、Open Graph等の共通メタ情報でカード表示する機能を追加。「スレを読む → リンクカード・Xのプレビュー → Webサイトのリンクカードを表示」で有効化。初期値はオフ。[詳細](site-link-cards.md)
- GIF専用ビューアを動画専用ビューアの任意パッチへ追加。[操作](video-viewer.md)
- NG管理、履歴、外部板、アップロード、メディア操作などの独自画面・ダイアログをCompose／Material 3へ移行。複数DEXの同梱とライブラリ隔離に対応。[移行範囲](compose-ui-migration.md)
- レスフィルターにAA・自分・返信と件数表示を追加。[使い方](response-quick-filters.md)
- 画面幅によるスマホ／タブレット表示の自動切替を追加。初期値はオフ。[詳細](fold-layout.md)
- Imgur投稿一覧の表示切替とCompose画面を追加。★スレの追加項目は初期未選択に変更。

## 修正

- 長押しワッチョイ検索の表示設定、全文検索のKyodemo／Hissi切替、投稿検索の設定トグル即時反映を改善。
- ZZZSearchを閉じた後も検索画面の更新通知を維持。動画サムネイルの生成設定を再配置し、旧版で無効にした設定を戻せるよう修正。文字サイズなどの小数入力キーボードを引き継ぐ。
- DAT落ちスレの一覧非表示を再公開時にも適用。下書き・送信済みを独立設定で非表示にできるよう追加。初期値はオフで、本文や履歴は削除しない。[詳細](hide-dropped-home-threads.md)
- 投稿者IDを対象にした標準NGの連鎖を補修。[仕様](poster-id-chain-ng.md)
- 手動サムネイルのURL解析をキャッシュし、同じ添付URLでの不要なキャッシュ破棄と更新通知を削減。報告された枠の消失・カクつきの改善を実機で確認したものではない。[確認範囲](manual-thumbnail-performance.md)
- 191／242のタブ復帰時の自動再読込を抑制する設定を追加。初期値はオン。「高度な設定」から切替可能。226の該当経路は未確認。
- バックアップのローカル／MEGA入口・保存対象の分離、★情報の復元、保存後の読み直し照合、進行・結果通知を改善。[詳細](mega-backup.md)

## パッチ容量と導入

絵文字フォント・191画像判定修正・実験用VPNの資材をMPPから分離し、必要なファイルだけ選んでAPKへ組み込む方式に変更。画像判定ZIPはリリースにも添付する。[初めての方の導入手順・直接ダウンロード・ライセンス](optional-assets.md)

## 確認範囲

対応対象は191 dev／226 dev／242 dev。最新ローカルMPPから191に全7パッチ、追加資材を適用し、再構築・署名・XIG05への別パッケージ導入とホーム起動を確認。サイトカード、GIF、VPNライブラリ、絵文字、画像判定修正のAPK同梱を確認した。191の下書き／送信済みフィルター14項目、投稿者ID連鎖の判定・フック確認は統合記録に記載。

サイトカードの実画面、全ダイアログ、折り畳み実機の開閉、タブ再読込の通信抑制、VPNの全経路は未確認。226／242について今回の最終統合版全体の実機動作を確認したものではない。

ローカルの最適化ビルドではAndroid LintのKotlin FIR内部例外のためLint工程を除外した。通常リリースは公式テンプレート由来のSemantic Release CIで生成する。最終的なCI結果と公開物はGitHub Actions／Releaseを参照。
