# Haiagaru 1.8.16

正式版とプレ版の取得先を1.8.16へ更新しました。対応はChMate 191 dev／226 dev／242 devです。更新前にバックアップしてください。

- **正式版1.7.1をご利用の方:** [追加機能・変更点・注意事項](https://github.com/areteruhiro/Haiagaru-Morphe/blob/master/docs/release-1.8.16-from-1.7.1.md)
- **プレ版1.8.15をご利用の方:** [今回の差分・操作案内・確認範囲](https://github.com/areteruhiro/Haiagaru-Morphe/blob/master/docs/release-1.8.16.md)

versionCode最大化を初期有効にしました。上／下4桁検索のバックグラウンド実行、保存履歴・結果内検索、保持設定とバックアップ、人気レスポップアップ、X表示の軽量化・カード表示、動画速度切替などを収録しています。

241／243は非対応です。versionCode最大化後は低いコードのAPKを通常上書きできません。任意・開発中機能を含み、全機能の実機通し確認は未完了です。各案内の制限と未確認範囲をお読みください。

配布物はAndroid向け `haiagaru_patches-1.8.16.mpp` です。Morpheへ登録済みの方は配布元を更新してください。
