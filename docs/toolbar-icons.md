# ツールバー表示・追加アイコン

対応: ChMate 191 dev／226 dev／242 dev。Haiagaru 1.8.13で追加しました。

Haiagaru設定 →「スレ・スレ一覧の表示」→「ツールバー表示・追加アイコン」から設定します。

- 対象は「エッヂ過去ログ」「フィルタ」「すべて既読」「長押しコピー」の4種類。
- 標準画像をGoogle Material Iconsのarchive／filter_list／done_all／content_copyへ統一。拡大しても解像度が落ちない24dpのベクターです。フォントや巨大な画像ライブラリは追加していません。
- ChMate標準のツールバー設定で、従来どおり表示・順番を変更できます。追加設定側でオフにした項目は全ツールバーで非表示になります。オンに戻した場合は標準側の表示設定に従います。
- 「画像を選択」からAndroidのファイル選択画面で任意の画像を指定できます。PNG／JPEG／WebPなどAndroidでデコードできる画像に対応。元画像は変更しません。
- 最大16MiB。画像は縦横比を維持し、透明な余白を付けた256×256 PNGに変換してアプリ内へ保存します。ツールバー上の寸法は標準アイコンと同じ24dpです。
- カスタム画像は元の色を維持します。暗い／明るいテーマの両方で見やすい画像を選んでください。
- 「標準のアイコンに戻す」でその項目だけ初期画像に戻せます。削除するのは取り込んだコピーのみです。
- 変更後はChMateを再起動してください。既存のタブ・ツールバーの並び順は変更しません。

標準アイコンの色付けはChMateに任せています。Haiagaru以外のアイコンや機能の表示設定には触れません。
カスタムアイコンの専用バックアップ対応は今回追加していません。

191／226／242の検証アプリで各28項目（標準描画、表示切替、任意画像のサイズ・色・余白、不正画像の拒否、初期画像への復帰）を確認済みです。システムの画像選択画面から選ぶ操作と、実際の各ツールバー上の表示は通し確認が残っています。
