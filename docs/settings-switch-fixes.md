# 表示スイッチ・反映処理の修正

## 修正内容

- ワッチョイ上／下4桁検索の表示スイッチがオンでも、標準メニューの初期オフに負けて表示されなかった経路を修正。
- 未設定の追加6アクションは初期オフを維持。検索機能全体がオフなら、子の表示スイッチをオンにしても検索項目は出さない。
- レス長押しの個別設定を優先。4桁検索画面で表示を切り替えた場合も同じ個別設定を書き換え、最後に変更した表示設定に揃える。
- ツールバー表示を明示的にオンにした場合、ネイティブの保存済み非表示フラグにも反映。標準の並び順は変えない。明示したオン／オフは全画面共通の指定として優先する。
- 機能一覧のHTTPS切替からも通信処理の実行時フラグを更新。
- コマンド候補オフでも、外部板の認証先登録・投稿準備は維持。
- 「ﾜｯﾁｮｲで検索」の初期アイコンをMaterialの検索ベクターに変更。配置設定のカタログ・従来メニュー・Composeメニューで同じリソースを利用。

## 再起動確認

ツールバーの表示・画像変更、すでに作成されたビューや起動時処理へ影響するスイッチでは「今すぐ再起動／あとで」を確認する。詳細設定と機能一覧は共通処理を使う。ユーザーが承認するまでは終了しない。

再起動では未保存の入力・アップロード・検索が中断される旨を表示する。設定保存を確認してから再起動を予約し、保存に失敗した場合は終了しない。Android側で再表示が遅延した場合はランチャーから開ける。履歴・保存データの削除はしない。

HTTPS・検索履歴・メニュー表示等、実行時に参照する設定は無用な再起動を要求しない。表示済みスレの再描画が必要な設定は、画面を開き直して反映する。
