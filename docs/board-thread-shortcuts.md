# 板・スレのツールバーショートカット

HOME／スレ内のツールバーカスタマイズ候補に「板・スレ」を追加。共有のカタログ・ラベル・独自アイコン差替えにも登録。初期の既存ツールバー配置は書き換えず、利用者の標準カスタマイズで配置する。

タップすると検索付きのコンパクトなネイティブAlertDialog（最大480dp／画面幅90%、一覧高さ45%）を表示。枠外タップ、戻るボタン／システムの戻るジェスチャーで閉じる。検索欄をタップするまでキーボードを出さない。登録済みboardsテーブルはバックグラウンドにて読み取り、追加URLと検索。板選択画面に一致しない場合も「板URLを手入力して追加」から登録可能。板／スレ追加画面の「板として登録」をONにすると未登録板のトップURLも板一覧へ直接渡す。スレURLは標準スレ画面、一般WebページはChMate WebViewActivityへ。登録済み板は板一覧へ直接開く。URLを選択するまでネットワーク要求はしない。

追加URLはメイン設定boardUrlShortcutsのJSONへ最大500件保存、SettingsProfilesで検証しローカルバックアップ対象へ。スレの新着数はChMateのブックマーク件数と既読数からバックグラウンド取得。通知NGがONで、対応するローカルDATが保存されている5ch／したらばは既存のNG判定分を差し引く。板未登録・未ブックマーク・未対応URLはバッジなし。表示名160文字、URL4096文字まで。JavaScript等のスキームとユーザー情報付きURLは拒否。更新履歴の機能一覧／アプリ・通信の基本設定にも管理入口を追加。

## スピナー初期値・手入力した板の判定修正

実機登録を診断したところ、したらばの板URL（/computer/45040/）が手入力URL扱いでWebViewActivityへ振り分けられていた。ChMate標準BBSUrlInfoパーサーで板・スレを判別し、判別できた場合はThreadListActivity／ResListActivityへ直接Intentを作成。追加外部板のURL変換・エッヂ正規化は既存関数を使用。一般WebのみWebViewActivity。ローカル変換が必要で標準判定できないスレ形式は既存OpenUrlActivityルーターを使用する。
