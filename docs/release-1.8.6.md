# Haiagaru 1.8.6 (Pre-release)

1.8.5からの変更点です。更新前に大切な設定・NG・履歴をバックアップしてください。

## 動画専用ビューア

- 添付として取得できたImgur・X・Instagram配信元のMP4を、アプリ内で再生・一時停止・シークできます。Imgurアルバム内の動画も取得対象に追加しました。複数の画像・動画がある場合はメディア取得設定に従います。
- Haiagaru設定の「動画を専用ビューアで開く」でオン／オフできます。初期値はオンで、オフなら従来の動作を維持します。
- 「戻る」「︙」とシークバーは画面タップで表示・非表示を切り替えます。操作パネルの自動非表示タイマーはありません。
- タイトル文字と上部ボタンの背景をなくし、白文字に黒い影を付けました。ボタンを隠しても動画の位置・サイズは変えません。
- ︙から外部アプリで開く、URLコピー、再読み込み、画面回転ができます。他アプリへ移動すると再生を停止し、戻っても勝手に再開しません。
- 対象は取得済みの対応MP4です。すべての動画サイト・形式、配信元のアクセス制限への対応を保証するものではありません。

## Imgur投稿一覧・アップロード（開発中）

パッチ導入時に「Imgurログインアップロード（開発中）」を選択した場合の機能です。初期状態は未選択で、導入後もログイン・有効化が必要です。

- ログイン画面とは独立した「Imgur投稿一覧」を追加しました。Haiagaru設定と、書き込み画面の「書き込む」の左にある︙メニューから開けます。
- 画像・動画のサムネイル、ページ切り替え、URLコピーに対応します。処理中・取得失敗は代替表示になり、一覧で動画本体を自動再生しません。
- 投稿をチェックして、表示ページの全選択／全解除と選択削除ができます。確認後にImgurサーバーから削除します。**削除は取り消せず、貼付済みURLも見られなくなります。** 端末の元ファイルや掲示板の投稿は削除しません。
- 動画アップロード後の処理待ち時間を0〜1800秒で設定できます（初期値120秒）。アップロードを繰り返さず、処理状況を確認します。結果不明時は投稿一覧を確認してから再送してください。
- Google認証後にImgurへ戻れず待機状態になる経路を改善しました。必要なGoogle認証先だけを許可し、GoogleログインだけでImgur認証完了と判定しません。
- API応答によるセッションCookie更新をWebViewへ反映し、リクエストごとに最新のCookieを使うよう修正しました。期限切れやサービス側のログアウトを無効化する機能ではなく、再ログインが必要になる場合があります。
- 非公式Web方式です。Imgur・Googleの仕様変更、利用規約・制限が適用され、ログイン・送信・長期のログイン維持を保証するものではありません。

## 操作・表示の改善

- ジェスチャー設定に「NG編集」を追加しました。既存のジェスチャー割り当てを優先し、標準のNG編集画面へ移動します。
- Haiagaru設定をAndroidの戻る操作で閉じられるようにしました。戻るでは未確定の変更を保存しません。
- 226 dev／241／242 devの自動スクロール速度調整ボタンをテーマに合う文字色へ補正し、暗いテーマで背景と同化する問題を改善しました。

## MEGA同期を任意のパッチへ変更

- パッチ導入時に選べる「MEGAバックアップ・同期」を追加しました。初期状態は未選択です。
- **MEGA同期にはAndroid 7.0以降が必要です。** 未選択時、またはAndroid 7.0未満ではMEGAの操作を表示せず、保存済みの自動同期設定やログイン情報があっても同期しません。
- ローカルバックアップ・復元は標準機能として維持します。MEGAパッチやログインは不要です。
- Cookieを含むローカルバックアップは暗号化されないJSONです。保管先と共有先に注意してください。

## 対応・検証範囲

- 主な対象：ChMate `0.8.10.191 dev`／`0.8.10.226 dev`／`0.8.10.241`／`0.8.10.242 dev`。243 devは引き続き非推奨です。
- Android向けMPPを配布します。Morpheのプレ版を更新後、元のAPKへパッチを適用し直してください。正式版の取得先は1.7.1から変更しません。
- 公開用1.8.6 MPPから4版へのパッチ適用、生成APKの動画ビューア・NGジェスチャー・Imgur投稿メニュー、226／241／242のテーマ色、MEGA選択／未選択の入口ガードを検証しました。Android下限の宣言は191がAPI 21、残る3版がAPI 23のままです。Morphe実画面での更新表示・ダウンロードは未確認です。
- 191の動画実再生・外部アプリ起動・背景移行時の停止、Imgurの認証確認・投稿一覧とサムネイル、模擬通信を使った処理待ち・選択削除をエミュレータで確認しました。実サーバーの投稿を削除する試験は行っていません。
- 最後に調整した動画操作パネルのタイマー無効化・ボタン装飾と、今回のMEGAオプションはビルド・生成APKの静的検証が中心です。242の確認用APKはエミュレータへインストール済みですが、今回の全変更を全版・全端末で実操作確認したものではありません。
- 新しいジェスチャーの手操作、動画の実アップロード・サーバー削除、長期のログイン維持、MEGAの実通信とローカル保存・復元の再検証は未完了です。実験的VPN・巨大バックアップについても従来の制約は継続します。
