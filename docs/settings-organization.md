# Haiagaru設定の整理

長い設定一覧を10カテゴリに分類し、必要なカテゴリだけ開けるようにしました。

- 基本設定
- スレ・スレ一覧の表示
- 書き込み
- 画像・動画・X／Twitter
- 必死チェッカー・専用ビューア
- NG・省略
- 履歴・保存件数
- 過去ログ・エッヂ検索
- バックアップ・データ移行
- 詳細設定・通信

上部で項目名・説明を検索できます。一致したカテゴリを展開して表示します。
複数の検索語はスペース区切り、英字の大小・全角半角を区別しません。
入力中の値やログイン情報を検索対象にはしません。
「クリア」「全て開く」「全て閉じる」も用意しました。

既存のコントロールそのものを分類しているため、値・対応版の判定・保存キーは変更しません。
カテゴリの開閉や検索では設定を保存せず、入力中の値も保持します。
「保存」で変更を反映、「キャンセル」または戻るで未保存の変更を破棄します。
別画面の編集・実行ボタンには、その画面独自の保存／確認動作があります。
入力値が不正な場合は設定全体を閉じず、対象カテゴリを開いて修正できます。
