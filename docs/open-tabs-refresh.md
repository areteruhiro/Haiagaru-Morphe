# 開いているスレ・板の一括更新

タブレット表示では、ツールバー設定の「開いているスレ・板を一括更新」を選んでボタンを追加できます。同名の項目をジェスチャー設定でも割り当てられます。初期状態でジェスチャーは割り当てません。既に使用中のジェスチャーを横取りしません。

実行時に両ペインの開いているタブを読み取ります。画面外で休止しているタブも対象で、HOME・空タブ・検索などのツールタブは対象外です。タブを切り替えたり選択状態を保存し直したりせず、スレは新着本文を取得し、板はスレ一覧を取得します。同じ板・スレは重複させず、取得対象のスレと同じ板のスレ一覧はスレ更新側の取得にまとめます。

「更新対象に含む」やお気に入りへ事前登録する必要はありません。これらの登録内容、通知監視、定期巡回の設定は変更しません。一括更新の対象はその回のWorkManagerリクエストに保存するため、別ウィンドウや後から開いたタブを混ぜません。通常の巡回とは別の作業名を使用し、通常の画像巡回設定がONでも板のみのリクエストでDATを取得しません。スレ更新のsubject取得から派生した別スレも本文の取得対象に混ぜません。

短時間の連打は3秒間抑制します。AndroidのWorkManager入力サイズ上限を超える場合は、取得前にタブを減らす案内を表示します。対応版は191／226／242です。

## 同時変更

- 追加の「登録済みNG（有効／無効）」ダイアログと自動起動フックを削除。標準のNG編集画面を直接表示します。Haiagaruのワッチョイ追加画面の同ダイアログ用ボタンも削除し、重複時は入力欄で案内します。NG条件自体は削除・変更しません。
- UAボタンに選択中のテンプレート名、下に保存中のUA全文と変更ON/OFFを表示。選択画面は現在のテンプレートにチェックが付きます。カスタムUAをテンプレートに誤表示しません。既存の通信UA・Cookie・ネイティブのクライアント識別名の扱いは変更しません。

検証記録は `integration-status.md` と `android-installations.md` に記載します。
