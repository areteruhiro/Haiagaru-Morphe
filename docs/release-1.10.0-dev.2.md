# Haiagaru 1.10.0-dev.2（プレリリース）

## Haiagaru設定を開くとクラッシュする問題

1.10.0-dev.1で設定画面を開くと、Composeの初期化中にメインスレッド用コルーチンを読み込めず終了する問題を修正しました。共通のCompose画面基盤を使う投稿検索・アイコン編集にも適用されます。

端末ログでは `Module with the Main dispatcher is missing` を確認しました。Android用コルーチンは同梱されていましたが、依存ライブラリの縮小設定がServiceLoaderを使う経路へ切り替えていました。DEX形式のMPEにはサービス登録ファイルが含まれないため、Android用の直接読み込み経路を残し、難読化後のクラス名も合わせるよう修正しました。

この修正後の端末起動で、ChMate本体のComposeクラスとの衝突による `EmptySemanticsElement` の `NoSuchMethodError` も確認しました。R8の保持ルールで元の名前が残るAndroidX／Kotlinクラスを、拡張DEXのマージ前にHaiagaru専用の名前空間へ移し、型の参照とリフレクション用のクラス名も揃えます。ChMate本体のクラスは変更しません。

## 更新方法

Morpheでこのプレリリースのパッチを取得し、元のChMate APKへ再適用してください。アプリのデータ消去は不要です。別パッケージへ入れた場合、設定や履歴の保存領域は元のアプリと別になります。

Compose画面や前回までの変更の説明は[1.10.0-dev.1の案内](release-1.10.0-dev.1.md)、実際のビルド・インストール・操作確認範囲は[統合記録](integration-status.md)を参照してください。

XIG05実機で191 devの別アプリへ先に導入して設定一覧の描画を確認し、その後226 dev／242 devでも設定画面の表示を確認しました。226では「スレを読む」、242では「バックアップ・機種変更」も表示でき、確認中の各プロセスに新しいクラッシュはありませんでした。全機能を通した確認ではありません。現行の対応版は191 dev／226 dev／242 devです。
