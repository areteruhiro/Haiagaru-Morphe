# 画像キャッシュ容量

対応版：0.8.10.191 dev／0.8.10.226 dev／0.8.10.242 dev。

ChMate標準の「画像キャッシュサイズ」で、従来の300MB／500MB／1GB／2GBに加え、
4GB／8GB／16GB／32GB／64GB／128GB／256GBを選択できます。
現在の設定値・初期値・既存キャッシュは変更しません。容量は事前に予約しません。

これはディスク上のキャッシュ容量で、画像を展開するメモリ容量の設定ではありません。
ChMateの整理処理・空き容量制約・Androidによるキャッシュ削除は引き続き適用されます。
キャッシュは永久保存ではありません。標準の容量整理処理は設定値の約85%を目安に削減します。

3版とも`imageCacheSize`のMiB値を`int-to-long`で変換してから容量計算し、
合計サイズと比較することを元APKで確認しています。
設定リソースの選択肢と保存するMiB値を同時に拡張し、地域別上書きも同じ件数にします。
既知の選択肢に一致しない場合はパッチ処理を失敗させ、別設定の配列を変更しません。
