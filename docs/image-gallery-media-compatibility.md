# 追加メディアと「画像」長押し一覧

対象: ChMate 191 dev / 226 dev / 241 / 242 dev。

本文内の画像はレスモデルの添付キャッシュへ展開される一方、画像一覧はDATからURLを抽出し直していたため、Imgurアルバム・X・Instagramなどの解決済み画像が一覧に入りませんでした。

- 191 / 226: ImageListActivityから生成される画像一覧フラグメントのURL抽出結果に `ImgurAlbumAttachments.complete` を適用します。
- 241: ImageListViewModelが使うDAT画像一覧ローダーのレスごとの配列走査直前に適用します。
- 242: 同ローダーの配列走査直前に適用し、抽出直後とキャッシュ再利用の両経路を通します。元の分岐先を補正呼び出しに保持します。

元本文、NG判定、URLの重複除去、画像の対象判定は変更しません。241 / 242のローダーはスレ情報の画像集計でも共有されます。メディア取得設定に従い、ネットワーク取得は既存の非同期処理を利用します。

一覧を開いた時点で解決済みのURLを含める補正です。一覧表示後の非同期取得完了による一覧の自動更新は対象外です。

検証: `VerifyImageListMediaHooks.java` で生成APKの画像一覧経路に補正が一度だけ入り、URL抽出より後に実行されることを確認します。生成APKでの実機表示は未確認です。
